# PepeHub 0.9.4 — разделы библиотеки и периоды статистики

## Что изменилось

- Боковое меню открывается кнопкой слева сверху или жестом от левого края. Два раздела: «Аудиокниги» и «Книги». Последний выбор сохраняется.
- Старые карточки распределяются по существующему формату: `audio` — аудиокниги, остальные — книги. ID, файлы, позиции, заметки и сессии не пересоздаются.
- Каждый раздел показывает собственные карточки, папки, команды добавления и статистику. Markdown-экспорт библиотеки также ограничен выбранным разделом. Тема оформления общая.
- Меню добавления аудиокниг не предлагает импорт текста, меню книг не предлагает импорт аудио. Мини-плеер остаётся в разделе аудиокниг. Само переключение раздела не останавливает фоновое прослушивание; открытие читалки, как раньше, ставит аудио на паузу.

## Папки книг

В разделе «Книги» кнопка папки открывает отдельный список. Поддерживаются подключение, повторное сканирование и отключение. Сканер находит EPUB, FB2/ZIP, TXT, Markdown, HTML, DOCX, PDF и RTF; исключает аудио и служебные папки `.pepehub`/Smart AudioBook Player.

На Windows читается исходный файл. На Android из выбранного дерева сохраняются URI и постоянное разрешение; только открываемый текстовый файл кэшируется в локальный seekable-файл для существующих движков чтения/PDF. Вся папка не копируется. Аудиофайлы по-прежнему читаются напрямую.

Текстовые книги сопоставляются по SHA-256: повторное сканирование, переименование или перемещение неизменившегося файла сохраняет ID карточки и позицию чтения. Регистрация результата сканирования атомарна. Лимиты: 64 МиБ для текстовых форматов, 256 МиБ для PDF; лимиты распаковки проверяет существующий парсер при открытии. ZIP рассматривается как FB2-архив. Заголовок карточки при подключении берётся из имени файла.

Отключение папки скрывает её карточки, если они не подключены через другой текстовый корень. Исходные файлы, позиции и история остаются; повторное подключение возвращает карточки. Недоступные/исчезнувшие файлы не удаляют историю. Изменение содержимого файла создаёт новую идентичность; автоматического сопоставления разных редакций текста пока нет. Чтение хэшей при обновлении пока полное, без постоянного индексатора.

## Статистика

Оба раздела имеют периоды «1 день», «7 дней», «30 дней», «Всё время», «Произвольный». «1 день» означает сегодня по местному времени. Произвольный период задаёт начальную и конечную дату и время; начало включается, конец исключается. Все вычисления границ сравнивают абсолютное время, интерфейс показывает локальное.

Аудиоинтервал, пересекающий границу произвольного периода, обрезается: время и пройденный материал учитываются пропорционально пересечению. Для первого/повторного прослушивания сохраняется учёт всей более ранней истории. Сессии и события ограничиваются выбранным периодом; JSON-экспорт сохраняет его границы. График показывает до 31 последнего календарного дня выбранного интервала. Серии дней, цели и сравнения недель/месяцев сохраняют свои отдельные календарные правила.

В выпущенной 0.9.4 статистика чтения использовала только ручные сессии `kind=reading`. В текущих исходниках 0.10.1 добавлены автоматические активные интервалы, календарь, цели, серии дней и статистика книги — [правила](READING_ACTIVITY_0101.md). Аудиостатистика остаётся отдельной. Пересекающиеся с границей ручные сессии чтения обрезаются пропорционально длительности.
