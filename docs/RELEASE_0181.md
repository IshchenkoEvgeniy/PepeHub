# PepeHub 0.18.1 — Android

4 октября 2026 года. Версия `0.18.1+47`, ARM64 versionCode `2047`, Android 7.0+ (min SDK 24, target SDK 36). Исправления раздела книжных рекомендаций после проверки кода и воспроизведения ошибок тестами.

- Названия с двоеточием, например «Dune: Messiah», больше не распознаются как ссылки и корректно отправляются в поиск. Проверено также реальным запросом Open Library.
- Неполный ответ источника с HTTP 200 не сохраняется в кеше как успешная карточка. Повторный запрос может получить исправленные данные; старые предупреждения исчезают после успешного дополнения. Время получения сведений обновляется без изменения личных заметок и исправлений.
- Завершившаяся во время возврата назад загрузка больше не закрывает предыдущий экран. Переход к настройкам источников временно недоступен во время получения карточки. Повторное нажатие «Сохранить» до следующего кадра не создаёт вторую ручную рекомендацию.
- Привязка ручной карточки к найденной книге сохраняет имена авторов с запятыми и другие неизменённые списки. Заполнение очищенного поля использует данные источника, сохраняя остальные ручные исправления, категории и заметку.
- Год первого издания произведения хранится и показывается отдельно от даты выбранного издания. Прямая ссылка на издание Open Library получает аннотацию и авторов по явно указанному родительскому произведению. Поддерживаются идентификаторы Open Library как с префиксом пути, так и без него.

Воспроизведены девять падающих сценариев до исправления. Добавлены 12 регрессионных проверок; удалены три повторявшихся теста без потери покрытия. Полный прогон: **189 Flutter-тестов успешно, 5 пропущены**; статический анализ без замечаний. Отдельный живой тест поиска и подробных карточек Inventaire, Open Library и Author.Today прошёл. Управление ПК не использовалось; физический Android-телефон не подключён.

APK ARM64: **33,112,592 байт**. Проверены подпись прежним тестовым ключом, версия, ABI, отсутствие режима отладки, ZIP-выравнивание 16 KiB, ресурсы аудиоуведомления и шрифты. Можно установить поверх предыдущей версии. SHA-256: `a352a91451b9edc4691d9e328a9508480cc545425d86bdc11ab74f2f97c43a99`.
