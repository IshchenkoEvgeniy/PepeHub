PepeHub 0.30.13 — исправления резервной копии библиотеки.

- В ZIP теперь входят сохранённые локально обложки с HTTPS-адресом. После переноса они доступны без подключения к сети.
- Для произведений в корзине копия собирает цитаты, заметки и историю чтения и прослушивания, даже если они ещё не открывались в библиотеке.
- Проверены восстановление в пустую базу, объединение и замена библиотеки из 1000 книг и аудиокниг с 1000 заметок и 1000 записей истории.

Windows x64 и Android ARM64, сборка 93 (Android versionCode 2093). До выпуска прошли 74 профильных теста и анализатор без замечаний. По просьбе пользователя тесты при выпуске повторно не запускались; проверяются сборки, версии, подписи и пакеты. Прежние ключи подписи сохранены.

После обновления создайте новую резервную копию: старые архивы могли не содержать перечисленные данные.
