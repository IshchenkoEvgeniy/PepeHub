PepeHub 0.21.6 — исправление удаления книг на Android

- Исправлена проверка доступа к файлу: на старых Android выданное право удаления могло ошибочно отклоняться.
- Если папка действительно доступна только для чтения, приложение предлагает восстановить доступ через системный выбор той же папки, затем продолжает подтверждённое удаление.
- Отмена останавливает операцию; другая выбранная папка не подключается и не заменяет текущую.
- Перед повторным удалением заново проверяются все файлы и их контрольные суммы. Изменённая за время выбора папки книга сохраняется.
- Поддержаны отдельные разрешения на файл и разрешения на родительскую папку. Ошибки показываются понятным текстом без PlatformException.

История версий остаётся выключенной по умолчанию. Прогресс, заметки и статистика при удалении файла сохраняются.

Обновление устанавливается поверх существующего PepeHub. Удалять приложение не нужно.
