# PepeHub 0.22.0 — музыка, синхронизация и быстрая загрузка

Версия приложения: **0.22.0+62**. Windows x64 и Android ARM64 (versionCode **2062**). Устанавливайте поверх прежнего PepeHub: удалять приложение и очищать данные не нужно.

- Музыка получила отдельное представление в «Медиа» и отдельный экран плеера: исполнитель, альбом, номер трека, встроенная обложка и редактирование сведений без изменения исходного файла.
- Добавлены повтор одного трека и плейлиста, «Играть следующим», перетаскивание и удаление из очереди. Очередь, текущий трек, перемешивание и повтор сохраняются после перезапуска. Недоступные файлы исключаются из восстановленной очереди.
- Статистика музыки отделена от видеокурсов и аудиокниг: время прослушивания, дни, треки и выбранный период. Старые позиции и история сохраняются.
- Включены музыкальные файлы, папки, ссылки и перемешивание из локальной сборки 0.21.9, которая ранее не была опубликована в канале автоматического обновления.
- Сопряжение устройств: QR-код на компьютере или телефоне, сканирование камерой Android и прежняя ручная вставка кода. Приглашение одноразовое, действует пять минут.
- Подключение общей папки проходит через мастер с предварительным просмотром локальных файлов, размера, разрешённых устройств и правил загрузки. Сам предпросмотр ничего в папке не создаёт.
- Спорные данные можно сравнить по полям. Для позиции чтения показываются глава, процент и фрагмент локальной книги вместо технического смещения.
- Загрузка библиотеки больше не выполняет отдельные запросы служебных флагов для каждой книги. Заметки выбираются по книге с индексом. Обзор аудиостатистики использует дневные итоги и запрос выбранного периода.

Для новых музыкальных полей синхронизации обновите оба устройства. Очередь сохраняется локально для каждого устройства. Если локального файла книги нет, контекст спорной позиции недоступен; для PDF показывается страница.

Камера QR, обмен ПК ↔ Android и аппаратный вывод звука требуют проверки на физических устройствах. Скорость на большой пользовательской базе отдельно не измерялась.
