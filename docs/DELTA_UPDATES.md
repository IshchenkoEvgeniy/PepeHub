# Дельта-обновления

Обновлятор поддерживает полные APK/ZIP и необязательные дельта-пакеты.
Первый переход со старого обновлятора требует полного пакета. После установки
поддерживающей сборки приложение выбирает патч именно для установленной версии.
Старые клиенты игнорируют новые поля манифеста и продолжают загружать APK/ZIP.

## Проверка и восстановление

Подпись Ed25519 покрывает адрес, SHA-256, размер патча, номер исходной сборки,
размер и SHA-256 исходного пакета. После скачивания проверяются хеши патча и базы;
после восстановления — размер и SHA-256 полного целевого пакета. Android затем
проверяет APK обычным путём, включая сертификат. Установщик Windows получает
обычный ZIP. Ни команды оболочки, ни исполняемый код из патча не запускаются.

Android читает собственный установленный APK. Windows использует проверенный
ZIP исходной версии в кеше обновлений; новый загрузчик сохраняет пакет текущей
установленной версии до успешного следующего обновления. Если база отсутствует,
изменена, патч недоступен или повреждён, приложение показывает причину и предлагает
отдельно скачать полный пакет. Автоматического перехода к большой загрузке нет. Сетевой обрыв
сохраняет частичный патч для докачки; отмена не запускает полную загрузку.
Пользователь может сразу выбрать полный пакет.

## Подготовка выпуска

`prepare-update.ps1` вызывает `prepare-update-deltas.ts`: берутся до двух
предыдущих локальных выпусков из dist/online. Если их нет, последняя публичная
сборка скачивается после проверки подписанного манифеста. Отсутствие базы не
препятствует выпуску полных пакетов. Патчи размером от 90% полного пакета
не включаются. Генератор рассчитан на полные пакеты до 512 МиБ.

Каждый созданный патч проверяется **тем же потоковым Dart-применителем**, который
работает в приложении (`tool/verify_update_delta.dart`). Результат должен
побайтно соответствовать исходному целевому APK/ZIP по SHA-256. Затем издатель
повторно проверяет файлы, включает описания патчей в подписанный `update.json`
и загружает их вместе с полными пакетами. Схема манифеста остаётся 1;
новое необязательное поле — `artifacts[platform].deltas`.

## Формат pepe-delta-v1

Файл начинается с восьми ASCII-байтов `PEPEDLT1`, затем uint32 little-endian
длины JSON-заголовка (до 4096 байт). Заголовок содержит version=1, baseSha256,
baseBytes, targetSha256, targetBytes. Далее идёт gzip-поток инструкций:

- 0: uint64 смещения в базе + uint32 длины, затем копирование из базы;
- 1: uint32 длины + буквальные байты (блок до 1 МиБ);
- 255: конец; дополнительные байты и неполный результат отклоняются.

Генератор использует границы блоков по содержимому (4–64 КиБ, средний блок
около 20 КиБ) и SHA-256 для сопоставления. Применитель ограничивает объём
распаковки, количество инструкций, границы копирования и длину результата.
Запись потоковая, оригинальная установка при восстановлении не меняется.

На реальных пакетах 0.26.0+74 → 0.27.0+75 получено: Android **6 497 924 байта**
вместо 70 273 390; Windows **6 825 433 байта** вместо 56 036 312.
Оба восстановленных пакета совпали с опубликованными по SHA-256.
Это измерение конкретного перехода, а не гарантированный размер будущих патчей.
