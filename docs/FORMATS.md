# Форматы PepeHub 0.12.0

В 0.5.3 подключение корня библиотеки предлагает отдельные книги по подпапкам либо отдельным аудиофайлам; диски объединяются с родительской книгой. [Каталог и ограничения](AUDIOBOOK_CATALOG.md). Аудиоформаты и принцип чтения оригиналов не изменены.

Папки аудиокниг подключаются **без копирования файлов** на Android/Windows. Сохраняются ссылки, порядок и позиция. Копирование отдельных выбранных файлов оставлено отдельной явной командой. Есть встроенные главы M4B и главы по отдельным аудиофайлам. [Прямое чтение из папки](AUDIOBOOK_LINKED_FOLDERS.md), [подробности многотрекового режима](AUDIOBOOK_MULTITRACK.md).

Поддержка формата означает подключение или импорт файла и открытие внутри приложения. Это не означает полную поддержку всех вариантов кодирования и вёрстки.

| Формат | Текущее поведение |
| --- | --- |
| EPUB | Текст глав в порядке spine, метаданные/обложка/серия; локальные сноски и иллюстрации в панели главы; без полной CSS-вёрстки |
| FB2 | Метаданные/обложка/серия, разделы, вложенный текст и стихи; сноски и встроенные изображения в панели главы |
| FB2.ZIP / ZIP | Один FB2 внутри архива; несколько книг в одном ZIP отклоняются |
| TXT | Абзацы, сохранение позиции, настройка размера шрифта |
| Markdown (.md, .markdown) | Текст заголовков, списков, таблиц и ссылок; без интерактивных ссылок |
| HTML (.html, .htm, .xhtml) | Текст блоков; скрипты, стили, изображения и внешние ресурсы не загружаются |
| DOCX | Основной текст и ячейки таблиц в порядке документа, метаданные; без точной вёрстки, рисунков, сносок и отслеживания исправлений |
| RTF | Текст и Unicode, Windows-1251/1252, абзацы; без форматирования, объектов и изображений |
| PDF | Обложка первой страницы, PDFium с поиском/оглавлением, цветными цитатами и заметками, темами, полным экраном, общей статистикой; текстовый режим с настройкой шрифта. Сканы без OCR не поддерживают поиск и извлечение цитат. [Подробности](PDF_READER_PARITY.md) |
| MP3, M4B, M4A | Импорт и существующий плеер |
| AAC, OGG, Opus, FLAC, WAV | Импорт с проверкой сигнатуры, существующий плеер; декодирование зависит от платформенного движка |

## Кодировки и пределы

Текстовые файлы: UTF-8, UTF-16 LE/BE с BOM. При отсутствии декларации и невозможности UTF-8 используется Windows-1251; это эвристика для кириллических библиотек, не универсальное распознавание языка. Для XML/HTML также принимаются объявленные Windows-1252, KOI8-R/U. Неизвестная объявленная кодировка отклоняется с сообщением. Для текста в иных кодировках пока требуется предварительное сохранение в UTF-8.

Лимиты импорта: PDF 256 МБ, книги/архивы 64 МБ, TXT/HTML/Markdown/RTF 16 МБ разобранного исходника; аудио 8 ГБ. Для FB2.ZIP/DOCX: максимум 5000 ZIP-записей, 256 МБ заявленного распакованного размера, 16 МБ на прочитанный раздел, 32 МБ фактического суммарного выхода. Для EPUB действуют более строгие пределы из документа EPUB_IMPLEMENTATION.md. PDF ограничен 20000 страницами. Показатели на максимальных размерах ещё не измерялись.

## Данные и синхронизация

Файл копируется в данные приложения без изменения исходника. SHA-256 определяет дубликаты. Перед появлением карточки проверяются структура и читаемость; для аудио только заголовок, полную декодируемость определяет плеер. Повторный импорт восстанавливает отсутствующую локальную копию.

В протоколе v1 расширен enum book.format: epub, fb2, txt, md, html, docx, rtf, pdf, audio. SQL-схема не меняется. **Сначала обновите/перезапустите сервер**, затем синхронизируйте новые форматы. Старый сервер отвергнет неизвестный формат, оставив операцию в локальной очереди. Для старых клиентов рекомендуется обновление: их интерфейс может неверно обозначать новые форматы.

Исторический прототип API не является завершённой синхронизацией: в 0.11.0 основной режим автономный, Cloudflare/Obsidian отложены. Сессии чтения и прослушивания учитываются автоматически. Заметки, позиции и планы хранятся локально; дневные журналы чтения сохраняются в `.pepehub/reading/logs/` подключённой текстовой папки. Полное переносимое восстановление текстовой библиотеки ещё не реализовано.

## Ещё не поддерживается

MOBI, AZW/AZW3, DjVu, старый DOC, CBR/CBZ и защищённые DRM-книги пока не открываются. Поддержка «всех популярных» не завершена. Следующий отдельный этап — движки/конвертеры для Kindle и DjVu и просмотр комиксов; переименование расширения не считается поддержкой. Для новых адаптеров используются единый реестр форматов, потоковый импорт и отдельные представления текста/страниц. Обход DRM не реализуется.

Реальные Android-устройства и полная матрица аудиокодеков ещё не проверены. Поддержка сборочной платформы библиотек не заменяет аппаратную приёмку.

## Основания выбора библиотек

[pdfrx](https://pub.dev/packages/pdfrx) предоставляет PDFium и Flutter-просмотрщик для Windows/Android; [enough_convert](https://pub.dev/documentation/enough_convert/latest/index.html) — дополнительные кириллические кодировки. ZIP, XML и HTML разбираются локально существующими библиотеками; файлы на сторонние сервисы не отправляются.
