# PepeHub 0.30.28

* Высота считается точно по реальному тексту под обложкой при вашем размере шрифта: две строки названия, автор, строка статуса и прогресс. Пустое место остаётся только у книг с названием в одну строку, примерно на одну строку текста.
* Карточка серии устроена как карточка книги:
* стопка обложек занимает всю высоту области обложки, сами обложки слегка обрезаются по краям;
* под названием — автор;
* ниже — «Завершено 2 из 3» с полоской прогресса;
* внизу — «3 аудиокниги · 18 ч 38 мин». Пустой тип не показывается, вместо «Книг: 0 · Аудиокниг: 9» теперь «9 аудиокниг».
* Время без секунд, если оно больше часа: «233 ч 9 мин» вместо «233 ч 9 мин 10 с». Для прослушанной до конца книги одно число: «26 ч 33 мин» вместо «26 ч 33 мин 16 с / 26 ч 33 мин 1…».
* Плашка статуса на узкой карточке теперь уменьшается, а не разбивается на две строки («Отложен а»).

Windows x64 и Android ARM64, сборка 108. Android versionCode 2108.
