PepeHub 0.30.15 — восстановление аудиоплеера после ошибки источника.

- После ошибки аудиоисточника выбор главы, кнопки перехода между главами, шкала книги и закладки открывают выбранное место напрямую. Повторное открытие сбойной главы больше не блокирует переход.
- При неудачном восстановлении сохраняется последняя позиция прослушивания для повторной попытки.
- Сообщение об ошибке содержит имя текущего файла и подсказку о выборе другой главы или повторном подключении папки; журнал сохраняет сообщение и индекс источника.
- Проверено, что оптимизация полки до одного файла не сокращает очередь воспроизведения: книга из 30 глав загружается полностью.

Только Android ARM64, сборка 95 (versionCode 2095). При подготовке исправления прошли 56 адресных Flutter-тестов, включая каталог из 500 книг, 500 аудиокниг и 50 001 трека; анализ изменённых Dart-файлов — без замечаний. При выпуске полный набор тестов повторно не запускался по запросу пользователя. Подпись, версия и целостность APK проверяются. Проверка исходного Source error на телефоне не выполнялась.
