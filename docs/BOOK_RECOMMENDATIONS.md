# Книжные рекомендации

Откройте **Меню → Рекомендации**. Это личные подборки книг: можно собрать «Топ магической фантастики», сохранить советы друзей или список будущего чтения. Раздел доступен на Android и Windows; новые установочные пакеты в этом выпуске подготовлены для Android.

## Добавление книги

Нажмите **Найти книгу в интернете**, введите название, автора или ISBN, затем выберите подходящий результат. Для Author.Today можно вставить ссылку `https://author.today/work/337592`; для Open Library поддерживаются ссылки на произведение или издание. Приложение получает подробную карточку выбранной книги и открывает её для проверки перед сохранением. Оно не выбирает автоматически первый результат и не объединяет разные произведения по совпавшему названию.

Доступные поля: название, авторы и соавторы, аннотация, обложка, жанры/темы, теги, цикл и номер, язык, дата издания, издатель, ISBN и страницы конкретного издания. Набор зависит от источника. Author.Today также сообщает число знаков и завершённость публикации. Эти сведения не считаются вашим прогрессом или временем чтения; неизвестные значения остаются пустыми.

**Добавить вручную** работает без интернета. В ручной карточке есть **Найти сведения в интернете**: после явного выбора книги заполняются пустые поля, а введённые сведения и заметка остаются. Для уже выбранного источника команда **Заполнить пустые поля из источника** дополняет пробелы, сохраняя ручные исправления.

## Подборки и заметки

Создавайте и переименовывайте категории. Одна книга может входить в несколько категорий и занимать разное место в каждом топе; место необязательно. В меню книги команда **В подборки** позволяет быстро изменить категории, сохраняя заметку и места в оставшихся подборках. Доступны сортировки по названию, автору, дате добавления и месту в выбранном топе.

В режиме **По месту в топе**, без поискового фильтра, книги можно перетаскивать за ручку или перемещать командами **Поднять / Опустить**. Эта операция перенумеровывает места только в выбранной категории; остальные топы остаются прежними. Есть поиск по сохранённым названиям, авторам, темам и личным заметкам. Отсутствие совпадений показывает **Ничего не найдено** и кнопку **Сбросить**; пустая подборка и отсутствие книг без категории отображаются отдельно.

На телефоне нажатие на сохранённую книгу открывает просмотр обложки, полной аннотации, заметки и категорий. Для изменения сведений нажмите отдельную кнопку **Редактировать**. После сохранения обновлённая карточка снова показывается в режиме просмотра.

Удаление категории сохраняет книги и заметки. Удаление рекомендации удаляет эту карточку из всех её подборок и требует подтверждения. Повторное добавление результата из того же источника открывает существующую карточку. Разные тома с одинаковым названием остаются отдельными книгами.

Подборки сохраняются в локальной SQLite-базе вместе с приложением и переживают перезапуск. Текстовые сведения, категории, места и заметки доступны без интернета; для загрузки обложки по сохранённой ссылке требуется сеть. Команда копирования выгружает подборки в JSON в буфер обмена. Облачная синхронизация этих новых подборок пока не реализована: обмен существующей библиотекой, журналом и заметками Obsidian продолжает работать отдельно.

## Источники

**Настройки → Источники книжных рекомендаций** или кнопка настройки поиска позволяют включать источники независимо. Ключи и вход в аккаунт не нужны.

- **Inventaire**: произведения, переводы, авторы, циклы и темы; аннотация Open Library дополняется только при явной связи идентификаторов.
- **Open Library**: зарубежные книги и конкретные издания. У выбранного издания показываются идентификатор и язык; только его данные используются для ISBN и страниц.
- **Author.Today**: русскоязычная фантастика; публичный поиск сайта и гостевые метаданные API. Поддерживаются обе разметки результатов. Номер тома берётся из `seriesWorkNumber`, а не внутреннего `seriesOrder`.

Один недоступный каталог не блокирует остальные. Результаты появляются по мере ответа каждого источника, и найденную книгу можно выбрать, пока другие каталоги продолжают поиск. Для источников показываются состояния поиска, число результатов и ошибки; команда **Повторить** запрашивает только ошибочный источник с исходным запросом, сохраняя остальные результаты. Уже сохранённые карточки того же источника и идентификатора помечаются **Уже в подборках**. Ошибки квоты, таймаута или формата ответа показываются отдельно от отсутствия результатов. Сбой дополнительного запроса жанров или издания сохраняет уже полученные сведения и показывает предупреждение. Есть ограничение размера ответа и памяти кеша, последовательные запросы к одному хосту и отмена запроса при таймауте. Кеш поиска действует в текущем процессе; сохранённые карточки хранятся постоянно.

Google Books, Hardcover, ISBNdb, аудиокаталоги и остальные изученные источники в этот выпуск не подключены. Их требования к ключам и ограничения зафиксированы в [исследовании источников](BOOK_RECOMMENDATIONS_SOURCES.md).

С версии 0.18.1 названия с двоеточием поддерживаются как обычный запрос. Год первого издания произведения показывается отдельно от даты выбранного издания, а прямая ссылка Open Library на издание дополняется по явно указанной связи с произведением. Это соответствует [различию произведения и издания в Search API](https://openlibrary.org/dev/docs/api/search). Повторное получение сведений очищает устаревшие предупреждения; некорректный ответ источника не мешает следующей попытке.

## Проверка

Новые автоматические тесты проверяют перезапуск базы, независимые места в топах, удаление категории без потери книги, защиту заметок и исправлений, дубликаты по идентификатору, частичные сетевые ошибки и мобильные сценарии. Отдельный тест выполняет реальные публичные запросы трёх каталогов; он включается переменной `PEPEHUB_LIVE_CATALOG_TEST=1`. Управление интерфейсом ПК и физическим телефоном для проверки не использовалось.
