# PepeHub 0.30.3 — быстрое открытие книг

31 октября 2026 · сборка 83 · Windows x64 и Android ARM64.

- PDF открывается сразу: при открытии разбирается только первая страница, остальные загружаются в фоне, начиная с места чтения. Раньше большая книга перед показом разбиралась целиком.
- Поиск, заметки, текстовый режим и статистика PDF не получают пустой текст ещё не загруженных страниц. Оглавление PDF читается при первом открытии, подсчёт текста для статистики начинается после загрузки страниц.
- Проверка PDF при импорте и создание обложки больше не разбирают все страницы.
- В режиме «Страницы» первые экраны показываются сразу, остальные страницы размечаются по мере листания. Особенно это заметно на книгах без глав (HTML, Markdown, DOCX, RTF, TXT без заголовков): большая книга раньше могла открываться около минуты.
- EPUB разбирается примерно в 4 раза быстрее, FB2 и HTML — примерно в 2 раза. Текст, разметка и сноски получаются такими же, как раньше, поэтому сохранённые позиции, цитаты и закладки остаются на своих местах.
- Как и в 0.30.2, на экране «Книги» нет верхней подсказки о карточках синхронизации без локального файла. Теперь это изменение есть и в Windows.

Устанавливайте обновление поверх текущего PepeHub. Удалять приложение не нужно.

## Проверки

- Новые регрессии: ленивое открытие PDF без чтения пустых страниц, совпадение статистики и текстового режима с полным открытием; быстрое схлопывание пробелов совпадает с прежним правилом на всех 65 536 кодах символов; поиск сносок EPUB совпадает с прежним; потоковая разметка страниц даёт те же границы; книга из одной главы на 1,2 млн символов открывается в режиме «Страницы» без полной разметки (до исправления — 38,8 с).
- Разобранные книги EPUB, FB2, FB2.ZIP, HTML, Markdown, TXT, DOCX и RTF (включая книги с сотнями сносок и разными пробелами) побайтово совпадают с результатом прежней версии.
- Большие PDF: 140 и 1500 страниц; открытие PDF на 1000 страниц — около 5 мс вместо 750–960 мс на настольном процессоре.
- Node: 55 прошли, 1 пропущена; TypeScript — без замечаний. Анализ Dart — без замечаний.
