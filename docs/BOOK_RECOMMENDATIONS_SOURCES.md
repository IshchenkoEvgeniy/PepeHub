# Источники данных для вкладки «Книжные рекомендации»

Дата проверки: 3 октября 2026 года. Это исследование перед реализацией; код приложения, Companion и плагина не изменён.

## Предлагаемое решение

Для первой версии использовать несколько источников. Author.Today подходит для русской сетевой фантастики и проверен на «Матабаре». После дополнительного исследования добавить Inventaire: он успешно нашёл зарубежное фэнтези с русскими названиями, авторами и связями с циклами. Open Library использовать для изданий и заполнения недостающих сведений. Google Books подключать с собственным ключом API после проверки его выдачи. Hardcover рассматривать как дополнительный источник с токеном. Для зарубежных аудиокниг отдельно проверена связка Audible/Audnexus. FantLab перспективен для классификации фантастики, но пока его доступность не подтверждена. ЛитРес требует отдельного партнёрского подключения.

Пользовательские подборки («Топ магической фантастики», «Хочу прочитать», «Посоветовали друзья») хранить в PepeHub. Одна книга может входить в несколько подборок, иметь позицию в топе и собственную заметку. Жанры из каталога не заменяют эти подборки.

## Проверенные запросы

Проверка выполнена HTTP-запросами из терминала без управления интерфейсом ПК, входа в аккаунты и изменений внешних данных. Полные аннотации и чужие отзывы в этот документ не копировались.

### Author.Today

Обычный [поиск «Матабар»](https://author.today/search?q=%D0%9C%D0%B0%D1%82%D0%B0%D0%B1%D0%B0%D1%80) вернул ссылку `/work/337592` и другие тома цикла. В форме сайта используется параметр `q`. Это страница сайта, не документированный JSON API поиска.

Получение карточки:

```http
GET https://api.author.today/v1/work/337592/details?recommendationsCount=0
Authorization: Bearer guest
```

Получены: название «Матабар», автор Кирилл Клеванский, обложка, аннотация длиной 742 символа с HTML, цикл «Матабар», `seriesWorkNumber: 1`, девять тегов, объём 1 080 861 знак. Жанры из `GET /v1/work/genres`: «Боевое фэнтези», «Приключения», «Фантастика».

Важное различие: `seriesOrder` здесь равен 0, а `seriesWorkNumber` равен 1. Для отображаемого номера использовать второе поле. `isFinished` означает завершённость публикации автором; это не статус прочтения пользователем. Ссылка автора на аудиоверсию и деление произведения на части могут отличаться от другого издания: совпадение одного названия недостаточно для автоматического объединения.

### Open Library

Для поиска переведённых книг использовать `q`, а не только `title`: поиск по `title` в этой проверке пропускал подходящие переводы. `lang=ru` предпочитает русский язык, но не гарантирует русское издание.

| Запрос через search.json | Результат проверки |
| --- | --- |
| `q=Матабар` | Нет результатов |
| `q=Гарри Поттер&lang=ru` | Есть «Дары Смерти» и «Проклятое дитя»; также фанфики. Нужно проверять автора и выбранное издание |
| `q=Последнее желание&lang=ru` | Подходящее произведение Сапковского не найдено среди полученных результатов |
| `q=The Last Wish author:Sapkowski&lang=ru` | Найдено произведение `/works/OL2577482W`, предложенное издание англоязычное |
| `q=Mistborn&lang=ru` | Найдены книги Брэндона Сандерсона, включая `/works/OL5738148W` |

У `GET /works/OL5738148W.json` подтверждены аннотация, обложки и темы. Отсутствие аннотации в поисковой выдаче не означает её отсутствие в карточке.

Это небольшая выборка, а не измерение полноты всего каталога. [Правила Open Library](https://openlibrary.org/developers/api) предусматривают кеширование и лимит 1 запрос/секунду для неопознанного клиента, 3 запроса/секунду для клиента с идентификацией и контактами. Для первого прототипа достаточно более низкого лимита; массовую загрузку каталога не выполнять.

### Остальные источники

Google Books: четыре запроса без ключа вернули HTTP 429 с ошибкой квоты. Перед интеграцией нужен собственный ключ и повторная проверка. Это не результат «книга не найдена».

FantLab: четыре запроса поиска получили отказ соединения. Повторить проверку перед подключением; не делать этот источник обязательным для работы вкладки.

Hardcover имеет [GraphQL API](https://docs.hardcover.app/api/getting-started/), но требует личного токена и защищённого серверного хранения. По коду BookLore подтверждена интеграция поиска по названию/ISBN, изданий, циклов и тегов. Это перспективное дополнительное подключение; его живую выдачу без токена не проверяли.

Для пользовательских подборок они не обязательны. Их можно рассматривать позже, если появится отдельный запрос на автоматический подбор похожих книг.

### Живые проверки новых источников

Inventaire:

```http
GET https://inventaire.io/api/search?types=works&search=Mistborn&lang=ru&limit=3
GET https://inventaire.io/api/entities/by-uris?uris=wd:Q2778373&lang=ru
```

Карточка «Пепел и сталь» содержит связи с автором `wd:Q457608` («Брендон Сандерсон»), циклами `wd:Q268100` («Рождённый туманом») и `wd:Q18535364` («Космер»), жанром фэнтези и датой публикации. Русская метка произведения не гарантирует русское издание или русскую обложку. В поиске есть изображение, но поле изображения в отдельной проверенной карточке отсутствовало: нельзя терять ранее полученные поля при объединении.

`GET /api/data/summaries?uri=wd:Q2778373&langs=ru|en` вернул ссылки на Open Library и англоязычную Wikipedia. Полноценная русская аннотация не подтверждена. Эти источники частично используют одни и те же данные, поэтому их согласие нельзя считать двумя независимыми подтверждениями.

Для списка URI в проверенном маршруте работает разделитель `|`. Вызов с неправильно переданным списком `relatives` получил 400; после удаления этого необязательного параметра карточка успешно получена. Реализация должна следовать актуальной спецификации, а не угадывать сериализацию массивов.

Проверенная цепочка поиска аудиокниги:

```http
GET https://api.audible.com/1.0/catalog/products?title=Mistborn&author=Brandon%20Sanderson&num_results=2&products_sort_by=Relevance
GET https://api.audnex.us/books/B002VA9IKK
```

Первый ответ содержит ASIN, а не все метаданные. Второй дал The Hero of Ages, автора Brandon Sanderson, чтеца Michael Kramer, длительность 1 645 минут, английский язык, обложку, описание и позицию 3 в The Mistborn Saga. Значит, поиск по названию цикла может вернуть другой том; нельзя автоматически выбирать первый результат. Endpoint Audible подтверждён текущим кодом Audiobookshelf, но отдельная официальная документация для такого внешнего использования не найдена — подключение сделать необязательным.

Apple Books: `GET https://itunes.apple.com/search?term=Mistborn%20Brandon%20Sanderson&media=ebook&entity=ebook&country=us&limit=2` и аналогичный запрос с `audiobook` вернули книги с обложками и описаниями. Наличие `trackCount` не означает длительность или число глав.

Эти сайты не выбирать обязательными источниками первой версии.

### Вывод для PepeHub

Базовый набор: Inventaire + Open Library для зарубежных книг и переводов, Author.Today для русской сетевой фантастики, Google Books после настройки ключа. Hardcover — дополнительное подключение с токеном, если его выдача окажется полезной на пользовательской выборке. Для аудио — отдельный необязательный провайдер Audible/Audnexus; LibriVox для классики. Apple Books и RanobeDB можно добавить позже для соответствующих каталогов. Платные подписки на этапе исследования не оформлялись.

Вместо десятка обязательных источников нужна расширяемая система провайдеров с приоритетами полей. Кешировать ответы и сохранять происхождение сведений. Если найдено несколько томов, языков или записей, показывать кандидатов. Жанры, оценки сайтов и описания не подменяют пользовательские категории, оценки и заметки.

## Правила будущей реализации

1. Ввод названия, автора при необходимости, ISBN или ссылки. Поиск возвращает несколько кандидатов с автором, обложкой, языком и источником. После выбора карточка заполняется автоматически всеми доступными сведениями.
2. Сохранять ID и ссылку источника, время получения, происхождение полей. Отсутствующие значения оставлять пустыми; не придумывать данные.
3. Различать произведение, конкретное издание и аудиозапись. Страницы и ISBN относятся к изданию, длительность и чтец — к записи. Не смешивать характеристики разных вариантов книги.
4. Интернет-данные обновляют библиографию. Собственные заметки, места в топах, оценки и журнал чтения сохраняются отдельно и не перезаписываются. Завершённость публикации не меняет статус чтения.
5. Обрабатывать ошибки сети, пустые результаты, 429 и недоступность одного источника. Ограничивать запросы, кешировать ответы и справочник жанров. Ключ Google хранить в Companion либо в настройках с подходящими ограничениями доступа; не вшивать общий секрет в APK.
6. HTML аннотации очищать; использовать только проверенные HTTPS-ссылки. Для поиска через HTML Author.Today предусмотреть независимый адаптер и резервный ввод ссылки, если разметка изменится. Перед включением адаптера проверить условия использования источника; доступность страницы сама по себе не гарантирует разрешение на любой способ её использования.
7. В тестах будущей реализации покрыть неоднозначные названия, разные издания, отсутствующие обложки, номер цикла, ошибки API и сохранность ручных заметок. Приложение в ходе этого исследования не менялось, поэтому его тесты повторно не запускались.

Следующий этап: реализовать локальные подборки и единый механизм поиска/автозаполнения, подключив только проверенные источники. Синхронизацию подборок с Obsidian определить отдельно: существующая синхронизация библиотечных карточек не создаёт её автоматически.
