# Личная библиотека

Библиотека PepeHub хранит завершённые книги и аудиокниги, оценки,
впечатления, цитаты и журнал. Рекомендации и подборка «Хочу прочитать»
остаются отдельным разделом; их категории и места в топах сохраняются.

Карточку можно создать без файла, подключения и известной даты окончания.
Основная полка показывает завершённые записи. Сортировка по умолчанию —
дата завершения, есть фильтр по году и отдельный вариант для неизвестной даты.
Действие «Уже прочитано / прослушано» в рекомендациях открывает карточку
библиотеки с заполненными сведениями и сохраняет связь с рекомендацией.

## Хранение и перенос

Собственный каталог находится в SQLite metadata (`library-catalog-v1`).
Он использует постоянные семантические имена свойств. Идентификаторы,
пути, YAML-псевдонимы, очереди операций и контрольные значения Obsidian
хранятся в адаптере отдельно (`library-exchange:<namespace>`).

При первом открытии импортируются ранее закешированные подключения,
включая отключённые. Старые хранилища и очереди не удаляются. Идентификаторы
при повторном переносе стабильны; совпадающие названия не объединяются.
Для связанных файлов сохраняется sourceBookId. Нестандартные свойства
карточек сохраняются, псевдонимы известных полей переводятся в локальную схему.

Незавершённые импортированные карточки доступны в «Импорт и экспорт →
Разобрать импорт». Их можно сохранить завершёнными или перенести в
существующие рекомендации. Перенос сохраняет исходную карточку и не
добавляет рекомендацию повторно.

## Обмен

Obsidian — необязательное подключение. Новые локальные карточки
экспортируются по выбору пользователя. Связанные карточки обновляются
по настроенному расписанию или при ручном обмене. Локальное сохранение
не ждёт сеть. Обложку можно выбрать локально; при экспорте её отправляют
отдельно, если обмен обложками включён.

Трёхстороннее сравнение сохраняет локальные правки и выявляет одновременные
изменения. Выбор версии находится в окне обмена. Удаление карточки из
Obsidian не удаляет запись PepeHub и не вызывает её автоматическое
восстановление в Obsidian. Отключение сохраняет каталог, заметки и журнал.

Локальные сессии и цитаты продолжают читаться из родных источников.
Импортированные записи без локального источника переносятся с привязкой
к личной карточке; отражения локальных источников повторно не добавляются.

## Завершение

Книги, отмеченные завершёнными в приложении, попадают в каталог при его
обновлении. Для аудио учитывается событие окончания последнего трека
издания. Изменения источников отслеживаются по revision, история
прослушивания выбирается по конкретной книге. Окончание произвольной
главы не завершает всю аудиокнигу. Уже сохранённая завершённая карточка
не возвращается в планы из-за изменения текущего статуса файла.

Тестовые сценарии дополнены, но тесты при этой работе не запускались
по просьбе пользователя.
