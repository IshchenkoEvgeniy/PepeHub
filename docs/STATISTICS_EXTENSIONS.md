# Расширения статистики

## Сравнение чтения

В статистике чтения раздел «Сравнение периодов» сопоставляет выбранные 1, 7, 30 или 365 дней с предыдущим таким же числом календарных дней. Для произвольного интервала сравнивается предыдущий интервал той же длительности. Учитывается выбранная книга. Метрики: время, число сессий, активные дни, новое продвижение. При нулевой базе процент не вычисляется; сегодняшний день явно помечен как незавершённый. «Всё время» не имеет предыдущего периода.

## Итоги года и категории

В верхней панели обзора есть отдельная страница «Итоги года». Она использует выбранные год и срез «Всё / Книги / Аудио» и общие источники обзора. Доступен PNG шириной 1080 px: завершения с перечитываниями, уникальные произведения, время, активные дни, самый длинный день, лучшая серия года с порогом 5 минут, любимый жанр, пять лучших книг по собственным оценкам и пять произведений по времени. Предполагаемое время из ручного прогресса аудио не участвует в рекордах дней и серий.

В годовой статистике и итогах доступны жанры, авторы и серии. Одна книга учитывается один раз в каждой своей категории; отдельная колонка завершений включает перечитывания. Повторные значения с разным регистром объединяются. Показаны первые пять категорий, полный список открывается лениво. Сумма групп может превышать число книг при нескольких авторах или жанрах.

## Общий JSON чтения и аудио

В верхней панели статистики — «Экспорт и импорт всей статистики». Формат `pepehub-complete-statistics`, версия 1. Сохраняются исходные reading-session, audio_event, ручные reading/listening-сессии, канонические записи журнала вместе с удалениями, заметками, происхождением и часовым поясом, годовые и дневные цели, планы, базовые автоматические значения прогресса, описания произведений и хеши файлов/треков. Файлы книг, аудио и изображения не включаются.

Импорт сначала проверяет файл и показывает число новых, совпадающих и конфликтующих записей. Применение выполняется одной транзакцией. Повторный импорт идемпотентен: существующие отличающиеся значения пропускаются, местные записи и удаления имеют приоритет. Совпадающие файлы сопоставляются пакетно по SHA-256. Зеркала исходных сессий не удваивают время. Планы и их ссылки переадресуются на найденные местные книги.

Описания импортированных произведений остаются представлениями статистики в `statistics-portable-v1`; они не создают карточки библиотеки или файлы на полке. Они сохраняют названия, завершения и категории даже без исходного файла. Изменение конфликтующей записи через импорт пока не предлагается. Перенесённые описания не открывают редактор несуществующей карточки. Импорт не включает системные разрешения и настройки уведомлений другого устройства.

Лимит файла — 64 МиБ, до 200000 исходных записей/сессий/строк журнала. Экспорт за пределами лимита завершается понятной ошибкой вместо создания файла, который нельзя импортировать. JSON кодируется и проверяется в isolate; обход базы остаётся согласованным снимком в транзакции. Этот перенос не заменяет резервную копию всей библиотеки.

## Уведомления целей и планов

«Цели → Напоминания о цели и плане», «План чтения → Цели и напоминания» или соответствующая категория настроек. Включение напоминаний, системных уведомлений, выбор целей/планов и местного времени сохраняются на устройстве. По умолчанию прежние напоминания внутри приложения сохраняют своё поведение. При системном режиме дублирующая подсказка внутри приложения отключается.

Android: канал `pepehub-goals`, запрос POST_NOTIFICATIONS на Android 13+, один AlarmManager `setAndAllowWhileIdle` на следующий день, перенос расписания после перезагрузки, смены времени/часового пояса и обновления приложения. Уведомление появляется не более одного раза за местную дату. Разрешение точных будильников не требуется; система может отложить доставку. После принудительной остановки нужно открыть приложение снова.

Windows: ежедневная задача текущего пользователя `PepeHub.GoalReminder.<SID>` запускает скрытый PowerShell и Windows toast. Создаётся ярлык с AppUserModelID в меню «Пуск». Не требуются права администратора; пользователь должен быть в системе. Пропущенный запуск разрешён после сна. Выключение удаляет задачу. Текст и время обновляются при сохранении целей/планов и запуске приложения. Для других платформ доступно прежнее напоминание внутри приложения.

## Проверки

- 28 тестов в statistics_extensions_test, statistics_consistency_test, reading_insights_test, reading_plan_test и settings_preferences_test: сравнение периодов, PNG, перенос между независимыми базами, повторный импорт, конфликты, хеши, удаления, недопустимый файл, узкий экран и каталог из 1000 книг + 1000 аудиокниг.
- Два Android Robolectric-теста ReminderReceiverTest: единственный будильник, смена часового пояса, отключение, одно уведомление за день и планирование следующего.
- `flutter analyze`: без замечаний. PowerShell разобран штатным parser, встроенный C# скомпилирован; PNG просмотрен визуально.
- Фактическая доставка уведомлений на физическом Android и через Планировщик Windows ещё требует ручного прогона. Проверки не создают реальную задачу и не включают уведомления на компьютере разработчика.

Отдельно остаются миграция общего JSON-журнала в таблицу и дневные проекции: см. STATISTICS_CONSISTENCY.md.
