# PDF и обмен файлами Android: изменения в исходниках

21.09.2026. После APK 0.12.0+25. Новые APK/ZIP по просьбе пользователя не создавались; номер версии пока не менялся.

## Большие PDF

Открытие оригинала больше не ожидает извлечения и хранения текста всей книги. Сначала открывается просмотрщик. Для статистики последовательно строится компактный индекс длин и смещений страниц; тексты и координаты символов всей книги в нём не хранятся. Уже сохранённый индекс используется повторно. Уход с экрана/закрытие прерывает незавершённый проход. Активное время и позиция сохраняются до готовности индекса; точные текстовые измерения начинаются после него, с новой сессии, без смешения единиц измерения.

Целевой кэш изображений просмотрщика уменьшен со 100 до 24 МиБ, предварительная отрисовка — до четверти экрана по вертикали. Полностраничный растр ограничен 4 млн пикселей и 3072 пикселями по длинной стороне. Это ограничения нашего отображения, а не гарантия общего расхода памяти PDFium: сложные встроенные изображения могут требовать дополнительную память декодирования.

Поиск читает страницы последовательно, сохраняет только первые 200 результатов с короткими фрагментами. Новая строка запроса, остановка и закрытие экрана отменяют предыдущий проход. UTF-16 позиции совпадают с выделениями и заметками.

Текстовый режим готовится только по команде пользователя, со счётчиком и отменой. Ограничение полного текста — 2 млн UTF-16 знаков; превышение оставляет доступным оригинальный PDF, поиск и заметки. Сканы без текстового слоя по-прежнему требуют OCR для текстовых функций. Предел импорта PDF 256 МиБ и предел 20000 страниц не увеличивались.

Без Android crash log нельзя подтвердить единственную причину исходного вылета. Убраны выявленные тяжёлые операции при подготовке; исходный файл нужно повторно проверить на телефоне после следующей сборки.

## Фиксация страницы

1. Открыть PDF, настроить масштаб и положение страницы.
2. Нажать замок рядом с поиском. Фиксируются масштаб и горизонтальное положение; остаётся вертикальная прокрутка. При необходимости расположение страниц переключается на вертикальное.
3. Для изменения масштаба/горизонтального положения снять замок.

Настройка хранится отдельно для каждой книги (`pdf-view:<hash>`). Кнопки страниц, поиск, оглавление и заметки продолжают работать. При повороте/изменении размера окна координаты ограничиваются границами документа.

## Android: поделиться и открыть

- В меню книги в библиотеке — «Поделиться файлом книги». Для обычной книги отправляется исходный формат; для аудиокниги — файлы глав (до 500), без создания архива и копирования аудиотеки.
- Отправка вызывает системный выбор приложения. Получатель получает временное право чтения конкретных URI. Файлы внутри приложения доступны через ограниченный `FileProvider`; SAF-файлы передаются существующими URI.
- «Открыть с помощью PepeHub» и «Поделиться → PepeHub» принимают один файл обычной книги: PDF, EPUB, FB2/ZIP, TXT, Markdown, HTML/XHTML, DOCX, RTF. Поддерживаются запуск закрытого приложения и новый файл при уже работающем приложении. Входящие аудиофайлы/пакеты нескольких книг этим обработчиком пока не принимаются.
- Входящий `content://` поток читается в рабочем потоке блоками 64 КиБ, проверяется размер. Затем штатный импорт проверяет формат и хеш, добавляет книгу в текстовую библиотеку и открывает её. Существующая книга определяется по хешу, её прогресс не сбрасывается. Временный файл удаляется после импорта/ошибки; старые незавершённые передачи очищаются через сутки при следующем приёме.
- Внешний документ сохраняется локально, поскольку временный доступ от приложения-отправителя может исчезнуть. Подключённые папки и аудиокниги продолжают использовать прежнюю модель доступа.
- При открытии другого экрана читалка приостанавливает учёт активного времени. Повторный запрос уже открытого файла не создаёт второго экземпляра читалки с тем же хешем.

Использованы системные механизмы [FileProvider](https://developer.android.com/reference/androidx/core/content/FileProvider), [временного доступа к файлам](https://developer.android.com/training/secure-file-sharing) и [intent-фильтров](https://developer.android.com/guide/components/intents-filters).
