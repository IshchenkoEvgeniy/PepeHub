# PepeHub 0.30.8 — общие сведения серии

Android ARM64 · сборка 88 · versionCode 2088.

- В общей форме добавления серии появились жанры и, для аудиокниг, чтецы. Поддерживаются несколько значений и подсказки из текущей библиотеки.
- В разделе «Издание и теги» можно указать язык, издательство, теги и формат текстовых книг: электронная или бумажная.
- Общие сведения переносятся в новые карточки. Индивидуальные изменения томов, включая очистку полей, сохраняются при последующем изменении общих значений. На шаге проверки видны жанры и чтецы каждого тома.
- При дополнении серии общие поля заполняются из существующих томов только при совпадении значений. Чтецы сохраняются только у аудиокниг. Подсказки общих полей вычисляются один раз при открытии формы.

При подготовке изменений ранее прошли 15 проверок серий и редактора; анализ изменённых Dart-файлов — без замечаний. Интерфейс просмотрен на мобильной, планшетной и широкой компоновках.

По запросу пользователя при выпуске тесты повторно не запускались: выполнена Android release-сборка со штатными проверками подписи, версии, архитектуры, выравнивания и ресурсов медиакнопок. Публикуются полный APK и подписанный файл обновления, без Windows-сборки и дельт. Аппаратная проверка телефона не выполнялась.
