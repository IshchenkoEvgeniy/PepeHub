# PepeHub 0.26.0 — экспорт Obsidian и схема базы 4

Windows x64 и Android ARM64. Версия приложения — **0.26.0+74**,
номер Android ARM64 — **2074**.

- Исправлен экспорт статусов и завершения книг: используются названия статусов
  выбранной коллекции Obsidian. Окончание последнего трека аудиоиздания
  учитывается как завершение книги; окончание отдельной главы — нет.
- EPUB/FB2 могут передавать прогресс в процентах. PDF использует страницы,
  аудио — минуты или часы. Указанный в карточке объём бумажного издания
  сохраняется при пересчёте доли текста. Длительности разных аудиоизданий
  больше не складываются как главы одной книги.
- Новый ввод метаданных: авторы, жанры и теги метками, офлайн-подсказки
  из библиотеки, поиск серии, календарь, выбор оценки и предпросмотр обложки.
  Имя файла аудиокниги можно разобрать на название, автора, часть и чтеца
  с подтверждением выбранных полей.
- При связывании карточки показаны обе версии данных. Можно выбрать,
  какие поля обновлять из приложения, какие оставлять в Obsidian, а где
  сохранять ручные правки. Пустые поля не стирают значения шаблона.
- Изменения метаданных отправляются в текущем цикле синхронизации.
  Кеш с отметками изменений по книгам уменьшает повторную обработку истории.
- Таблицы, индексы и триггеры функций перенесены в единую миграцию схемы **4**.
  Существующие итоги не пересчитываются повторно. Аудио- и видеоиндексы
  защищены от повреждённого JSON; запросы журнала используют индексы.

**Перед миграцией приложение создаёт копию `backups/before-v4-*.sqlite`.**
Имя рабочей базы сохраняется. Версии 0.25.x не открывают схему 4:
для отката нужна резервная копия до обновления.

Для передачи настроенных статусов и новых единиц требуется обновлённый мост
Habit Timer (`scripts/install-obsidian-library-bridge.ps1`) и перезапуск
плагина Obsidian. На этом ПК мост уже обновлён и собран. Дополнительные
поля совместимы с существующим Companion; развёртывание сервера не выполнялось.

Статический анализ Flutter и TypeScript, сборки Windows и плагина успешны.
SQL схемы проверен на SQLite 3.53.1, форма — вручную в изолированном
предпросмотре шириной 390 px. **Flutter- и TypeScript-тесты при подготовке
этого выпуска не запускались по указанию пользователя.**
На физическом Android изменения не проверялись.

Сертификат Android и ключ подписи обновлений сохранены.
