# Загрузка библиотеки, заметок и статистики

Изменения в рабочих исходниках от 23 октября 2026 года.

- `LibraryPage._reload`: служебные флаги скрытия и статуса книг/аудиокниг читаются одним запросом по индексированным префиксам через `Repository.metadataPrefixes`. Отдельных запросов этих флагов на каждую книгу больше нет. Сами книги и сессии пока загружаются целиком.
- `ReadingLibrary.notes`: фильтры `hash` и `bookIds` применяются в SQLite до декодирования JSON. Частичные индексы `reading_notes_hash` и `reading_notes_bookId` относятся только к заметкам. Повреждённый JSON чужой заметки не мешает открыть заметки выбранной книги. Повреждённая выбранная запись продолжает выдавать ошибку, а не исчезает молча.
- `StatisticsHubPage`: собственная история аудиокниг больше не выгружается целиком в Dart. Пожизненные итоги читаются из `audio_daily_totals_v1`; выбранный год агрегируется SQL-запросом по пересекающим период интервалам с индексами времени начала/окончания. Сохраняются правила часового пояса, обрезки на границах периода и ручных записей без известного времени. Чужие записи Obsidian пока обрабатываются прежним способом, с существующим исключением дубликатов.

Таблица дневных итогов — восстанавливаемая проекция исходных `audio_event`. Она создаётся и заполняется один раз в транзакции при первом обращении к статистике. Триггеры обновляют её при увеличении чекпоинта, редактировании, синхронизации, мягком/физическом удалении и восстановлении; откат исходной транзакции откатывает и проекцию. Схема основных данных и формат синхронизации не меняются. Первое заполнение и создание индексов требует прохода по имеющейся истории; последующие открытия используют готовые индексы и итоги.

Проверки находятся в `test/music_sync_performance_test.dart`: пакетная выборка, выборка заметок, пересчёт при всех видах записи, откат, сравнение с прежней аналитикой на границах года и часовых поясов. Замеры на большой пользовательской базе не проводились; конкретный выигрыш по времени и памяти требует профилирования.
