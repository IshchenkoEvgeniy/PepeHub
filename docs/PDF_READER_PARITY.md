# PDF: обложки и общие инструменты чтения

21.09.2026. Изменения после 0.11.0+24 включены в выпуск [0.12.0+25](RELEASE_0120.md). Пакеты 0.11.0 этих изменений не содержат.

После этого APK в исходники внесены [оптимизация больших PDF, фиксация страницы и обмен файлами Android](PDF_ANDROID_FILES.md). Новая сборка не создавалась.

## Библиотека

- Обложка — первая страница PDF, PNG с длинной стороной 600 пикселей. Кэш `reading-covers/<hash>.png`; исходный PDF не меняется.
- Уже добавленные PDF автоматически индексируются при открытии раздела «Книги». Команда «Обновить сведения из файла» повторяет извлечение. Ручные поля карточки и выбранная пользователем обложка имеют приоритет.
- Android SAF отдаёт последовательный поток. Для извлечения обложки используется один временный файл до 256 МиБ; после обработки он удаляется, остаётся только миниатюра. Это не постоянное копирование всех книг в кэш чтения. Открытие PDF через SAF по-прежнему использует существующий кэш открываемой книги.
- Старый ключ позиции `pdf:<hash>` переносится в общий `reader:<hash>` без сброса страницы. Обложки и текстовый индекс не перезаписывают ручные исправления, заметки, коллекции или избранное.

## Чтение оригинального PDF

Меню справа сверху: оглавление/страницы, цитаты и заметки, заметка к странице, оформление, текстовый режим, полный экран, масштаб. Поиск вынесен отдельной кнопкой.

- Встроенное оглавление; при его отсутствии — список страниц. Внутренние ссылки, в том числе ссылки на сноски, ведут на страницу назначения; внешние URL автоматически не открываются.
- Поиск текстового слоя с подсветкой результата. Иллюстрации, таблицы и исходная вёрстка остаются частью оригинальной страницы.
- Горизонтальное расположение страниц либо вертикальная прокрутка, светлая/тёмная/сепия/системная тема, масштаб, полный экран, настраиваемые действия зон нажатия. Тёмная тема инвертирует всю страницу, включая изображения.
- Шкала книги, процент, номер страницы, история последних 20 намеренных переходов и возврат. Перетаскивание шкалы создаёт один переход после отпускания. Естественное перелистывание не засоряет историю.
- Выделение текста → «Цитата / заметка»: цвет, комментарий, теги, персонажи. Выделение через несколько физических страниц сохраняется отдельными привязанными к страницам цитатами с одинаковыми полями комментария/тегов. Их можно редактировать независимо.
- Общая страница заметок обеспечивает поиск, фильтры по цветам/тегам, редактирование, отмену удаления и экспорт Markdown/JSON для книги или всей библиотеки. Нажатие открывает исходную страницу и фрагмент.
- Заметка к странице доступна и без текстового слоя.

## Текстовый режим и статистика

«Текстовый режим» открывает существующую общую читалку на извлечённом тексте PDF. Там доступны шрифт, размер, межстрочный интервал, поля, прокрутка/перелистывание и остальные общие текстовые инструменты. Одна исходная страница соответствует одному разделу; позиции и цитаты используют точные UTF-16 координаты того же текста, что и оригинальный просмотрщик. Можно вернуться в оригинал кнопкой «Назад».

Общая статистика: активное время, сессии, новое продвижение и повторное чтение, календарь, серии дней и цели. В оригинальном PDF продвижение подтверждается обычным переходом на следующую страницу; последнюю страницу можно завершить отдельной кнопкой. Поиск, оглавление, ползунок и возврат отмечаются как переходы и не прибавляют пропущенный текст. Открытые панели и фон исключаются. При переключении режимов предыдущая сессия закрывается, чтобы два счётчика не перезаписывали покрытие книги.

Индекс текста позволяет существующим планам оценивать оставшийся объём и время по собственной скорости, когда накоплены достаточные измеренные интервалы. До первого открытия PDF доступна позиция по страницам; после извлечения — доля текстового объёма. Это может изменить процент без перемещения страницы.

Журналы используют общий механизм `.pepehub/reading/logs/<дата>/reading-<дата>.json` и резервный `.bak` для подключённого корня. Частые проверки активности не создают отдельных файлов. Заметки остаются в общей базе приложения, доступны для явного экспорта; переносимые снимки всей библиотеки пока отдельный будущий этап.

## Ограничения и проверки

- Сканы без текстового слоя: оригинальные страницы, обложка, масштаб, темы, позиция, заметки к страницам и активное время работают. Поиск по содержимому, цитаты из текста, текстовый режим и прогноз по объёму требуют OCR; OCR не добавлен.
- Запрет копирования в PDF соблюдается: извлечение текста и цитат не включается.
- В текущих исходниках оригинал открывается без ожидания извлечения полного текста. Индекс статистики хранит только длины/смещения страниц. Текстовый режим готовится отдельно, с отменой и ограничением 2 млн UTF-16 знаков; превышение не блокирует оригинал. Проверено раннее открытие PDF на 1500 страниц; максимальные 20000 страниц ещё не проверялись.
- Текстовый режим не воспроизводит колонки, изображения и типографскую вёрстку оригинала. Для них используется режим страниц.
- Тесты `test/pdf_reader_test.dart` запускаются на уже существующей PDFium-библиотеке через `PEPEHUB_PDFIUM`, без сборки приложения. Проверяются первая страница/размер PNG, миграция прогресса, сохранность ручной обложки, SAF-поток и удаление временного файла, поиск/возврат, заметка к странице, цитата через две страницы, темы/полный экран и переключение режима без двух активных сессий. SAF в тесте — имитация Android-канала; аппаратная проверка телефона остаётся.
