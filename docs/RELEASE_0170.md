# PepeHub 0.17.0 — Android

3 октября 2026 года. Версия `0.17.0+45`, ARM64 versionCode `2045`, Android 7.0+ (min SDK 24, target SDK 36). APK подписан прежним тестовым ключом и устанавливается обновлением с сохранением данных.

- Добавление книги в Obsidian автоматически заполняет доступные сведения файла, сохранённый прогресс, даты, измеренное время чтения/прослушивания и найденную обложку. EPUB/FB2 дают язык, жанры, издателя, ISBN, сведения о публикации и другие встроенные свойства; HTML/DOCX также сохраняют доступные метаданные. На Android длительность и теги аудиофайлов считываются без запуска воспроизведения. Неизвестные значения остаются пустыми.
- Для PDF прогресс выражен в страницах, для текстовой книги без точного числа страниц — в символах, для аудио — в минутах. Длительность аудиокниги и время, потраченное на прослушивание, учитываются отдельно. Пустые поля связанных карточек дополняются автоматически; последующие ручные правки в Obsidian сохраняются.
- Добавлена двусторонняя синхронизация цитат, комментариев, тегов, персонажей, цветов выделения и аудиозаметок с позицией. Обычный текст карточки Obsidian также передаётся, сохраняя YAML и журнал. Есть отдельный экран «Настройки → Заметки Obsidian», переключатель обмена и выбор версии при конфликте. Повторные запросы и удаления не создают дубликаты.
- Исправлен сбой ввода в читалке: появление клавиатуры больше не пересоздаёт область текста с перехватом фокуса у комментария, тегов или персонажей. Авторов и жанры можно вводить обычным текстом через запятую или точку с запятой. Исправлен двойной учёт заранее заполненного времени при первом переносе журнала.

Обновлённый Companion опубликован, мост установлен и собран в используемом плагине. **Перезапустите Obsidian**, чтобы он загрузил новый код. Для обмена заметками локальную книгу нужно связать с карточкой Obsidian; файлы книг и аудио не передаются. [Подключение и устройство обмена](OBSIDIAN_LIBRARY.md).

Проверено: 154 Flutter-теста успешно, 4 пропущены; анализатор без замечаний, 29 серверных тестов, TypeScript typecheck, 10 тестов моста и сборка плагина. Проверка клавиатуры выполнена регрессионным тестом с изменением отступов при её появлении. Физический Android-телефон не подключён; управление ПК не использовалось.

APK: **32,915,416 байт**, SHA-256 `69ce2617ebdef5ebbfb44775df24687d116467d51c074e4bcda6eb81659b6983`. Проверены совпадение сертификата с предыдущими выпусками, версия и SDK, ARM64, отсутствие режима отладки, ZIP-выравнивание 16 KiB, ресурсы медиаплеера и шрифты.
