## 3. Удобство сети и платформ

- [x] Постоянный кеш хешей по атрибутам, наблюдатель Windows, редкая контрольная проверка и обход SAF без перечитывания неизменившегося содержимого при достоверных атрибутах.
- [x] Автообмен по изменению контрольной суммы индексов, один инициатор, задержка событий и повторов при ошибке, отключение автообмена; условная выдача неизменившегося файлового индекса. [Поведение и сравнение с Syncthing](DEVICE_SYNC_INCREMENTAL.md).
- [x] Перенос полного хеширования Windows с UI isolate; нативный worker для SAF.
- [ ] Асинхронные сетевые задания первичной индексации и измерение производительности больших папок.
- [ ] Переиспользование соединений/потоковая передача, квоты, уборка незавершённых загрузок, пагинация и дельты изменённых индексов, повторное использование блоков изменённого файла.
- [x] Подписанное LAN-обнаружение и проверенное обновление адреса без повторного сопряжения; ручной запасной путь.
- [x] Выборочная загрузка для каждого устройства: без файлов / выбранные / вся папка.
- [x] Необязательный WSS-ретранслятор без хранения библиотеки, fallback с прямого TCP, локальные сквозные проверки; [настройка сервера](PEER_RELAY.md).
- [ ] Прямое соединение между разными сетями, глобальное discovery/NAT traversal; развёртывание и внешняя приёмка ретранслятора.
- [x] Android JobScheduler для короткого обмена данными, отдельный headless-движок и передача медиа с уведомлением; сеть/батарея и таймаут ОС. Физическая приёмка остаётся ниже.
- [ ] Физическая приёмка Android и Windows, большие библиотеки, сетевые разрывы и заполненный диск.
- [ ] Удобное восстановление/управление сохранёнными версиями и журналом конфликтов.
