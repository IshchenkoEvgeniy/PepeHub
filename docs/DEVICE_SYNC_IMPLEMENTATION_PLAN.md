# Прямая синхронизация — этапы

Спецификация: [DEVICE_SYNC_SPECIFICATION.md](DEVICE_SYNC_SPECIFICATION.md). Начало: 15 октября 2026.

Приоритет зафиксирован: общие папки синхронизируются **напрямую**; облако является дополнением. `[x]` — реализовано и проверено указанным способом, `[ ]` — остаётся в работе. Библиотечные данные и физическая приёмка не считаются готовыми вместе с файловым протоколом.

## 1. Прямой файловый движок

- [x] Локальная идентичность устройства, адаптер защищённого хранилища ключей, отзыв сопряжения.
- [x] Приглашение на пять минут для одного устройства, шифрованный прямой канал, ограничения протокола.
- [x] Общие папки с независимыми локальными путями и явными разрешениями устройств.
- [x] Сканирование, полный хеш содержимого, векторы версий, двусторонний обмен.
- [x] Ограниченные блоки, докачка, проверка SHA до публикации.
- [x] Конкурентные версии, удаления, версии прежних файлов; проверка локальной правки перед публикацией. Произвольная внешняя гонка в момент операции ОС не исключена.
- [x] Проверка путей/регистра, блокировка ссылок и сохранение индекса при недоступном корне.
- [x] Windows filesystem и адаптер Android SAF; Kotlin скомпилирован, аппаратная приёмка остаётся в этапе 3.
- [x] Экран устройств/папок, состояния, предложения папок, ручной и периодический обмен.
- [x] Проверки двух экземпляров без облачных API и регрессия приложения.

## 2. Прикладные данные поверх прямого канала

- [ ] Общие ID книг/курсов и локальные привязки файлов, миграция уже существующих библиотек.
- [ ] Позиции текстового/PDF/аудио/видео с версиями содержимого и выбором конкурентных позиций.
- [ ] События статистики с дедупликацией по ID, покрытия и исправления.
- [ ] Заметки, закладки, Anki, субтитры, коллекции, рекомендации и общие настройки.
- [ ] Слияние независимых правок, сохранение спорных версий, tombstone и восстановление долго отсутствовавшего устройства.
- [ ] Обновление открытых экранов без внезапной перемотки текущего плеера.

## 3. Удобство сети и платформ

- [ ] Кеш сканирования, асинхронное построение индекса и перенос хеширования Windows с UI isolate; производительность больших папок.
- [ ] Переиспользование соединений/потоковая передача, квоты, уборка незавершённых загрузок, пагинация индексов.
- [ ] Автоматическое обнаружение и обновление изменившихся адресов.
- [ ] Прямое соединение между разными сетями, discovery/NAT traversal; при необходимости шифрованный ретранслятор без обязательного облачного хранения.
- [ ] Android background scheduler/foreground transfer, ограничения батареи и сети.
- [ ] Физическая приёмка Android и Windows, большие библиотеки, сетевые разрывы и заполненный диск.
- [ ] Удобное восстановление/управление сохранёнными версиями и журналом конфликтов.

## 4. Необязательное облако

- [ ] Аккаунт и изоляция профилей, без зависимости прямого режима от интернет-входа.
- [ ] Лёгкий режим прикладных данных.
- [ ] Выборочное/полное облачное хранение файлов, независимая политика скачивания устройства.
- [ ] Восстановление доступа и резервные копии, история версий.

## Проверки

Первый файловый этап экспериментальный; прикладной обмен и облако не реализованы. Реализация находится в `apps/pepehub/lib/sync/peer/`, Android-адаптер — `PeerFilesChannel.kt`. Существующий облачный `/v1` не используется и не расширялся этим этапом.

15 октября 2026:

- `peer_sync_test.dart` и `peer_wire_security_test.dart`: 14 проверок — изолированные устройства/БД, реальный loopback TCP, взаимное сопряжение, разные корни, двусторонний обмен, запрет чужой папки, пауза, отзыв и перевыпуск ключа; конфликты, удаления, SHA, докачка; неподходящий ключ, повтор запроса, повреждение шифротекста и слишком большой пакет. Экран телефона проверен при ширине 360 и масштабе текста 1.3. Ключи в тестах заменены отдельным хранилищем в памяти.
- `audio_mini_player_navigation_test.dart`: экран открывается из настоящих настроек на телефоне/ПК; одна рабочая панель аудиокниги сохраняется. Правая панель настроек получила прокрутку.
- Android `:app:compileDebugKotlin`: успешно. Это компиляция исходников, не физическая проверка SAF и не опубликованный APK.
- Итоговая регрессия Flutter: **371 passed / 11 skipped**, ошибок нет (`apps/pepehub/build/peer-sync-full-tests.log`). `dart analyze --fatal-infos`: **No issues found** (`peer-sync-analyze.log`). Сетевые адаптеры, брандмауэр, системное хранилище секретов и реальные накопители проверяются отдельной физической приёмкой.
