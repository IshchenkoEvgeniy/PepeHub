# Удобство читалки: следующий пакет после 0.22.2

## Реализовано

| Сценарий | Поведение |
|---|---|
| Поиск | «Е» и «ё» равнозначны, последовательности пробелов и переносов строк совпадают. Регулярные выражения в запросе остаются буквальным текстом. Поиск работает по исходной строке: позиции выделений, заметок и символов PDF не сдвигаются. |
| Закладки | Кнопка внизу читалки и `Ctrl+D` сохраняют текущее место одним действием. В полноэкранном режиме есть отдельная кнопка. В списке показаны глава, процент книги и фрагмент текста; переименование и отмена удаления сохранены. |
| Выделение | Прокручиваемые режимы используют общую `SelectionArea`: можно выделять несколько абзацев обычным жестом. Смещения берутся из локального диапазона каждого абзаца, без поиска выбранной фразы в книге. Копирование через меню и `Ctrl+C` сохраняет исходные переносы между абзацами. |
| Настройки | В текстовой читалке оформление предварительно показывается на книге с задержкой 150 мс. Закрытие шторки сохраняет выбор, «Отмена» возвращает прежние настройки. В PDF закрытие шторки также сохраняет выбор и есть явная отмена. |
| Тема и шрифт | Для нового профиля — системная тема; явно сохранённая тема сохраняется. Встроенный шрифт без засечек подписан Onest. |
| TXT | Распознаются явные заголовки «Глава 1», «Часть II», «CHAPTER 2», «Part One» и первые десять порядковых названий на русском. Обычные одиночные переносы строк не превращаются в отдельные абзацы, чтобы не испортить книги с жёстким переносом строк. |

В меню текстовой и PDF-читалки есть справка «Горячие клавиши».

| Клавиши | Текст | PDF |
|---|---|---|
| Пробел / Page Down | Вперёд | Следующая страница |
| Shift+Пробел / Page Up | Назад | Предыдущая страница |
| ↑ / ↓ | Прокрутка; в перелистывании — страница | Штатный сдвиг просмотрщика |
| ← / → | Страница | Штатный сдвиг просмотрщика |
| Home / End | Начало / конец книги | Первая / последняя страница |
| Ctrl+плюс / Ctrl+минус | Размер шрифта, 12–56 | Масштаб; учитывается блокировка |
| Ctrl+D | Быстрая закладка | Заметка к странице |
| Ctrl+B | Список закладок | — |
| Ctrl+F | Поиск | Поиск |
| F3 / Shift+F3 | Следующее / предыдущее совпадение | — |
| F11 / Esc | Полный экран / выход | Полный экран / выход |

Команды чтения не выполняются поверх другой открытой страницы/диалога или при вводе текста.

## Перенос данных TXT

`currentBookLayout = 5`. Парсер сохраняет точную конкатенацию текстов прежних глав, включая исходные разделители. `ReaderLinearRebase` переносит позиции по абсолютному смещению. Изменения позиции, истории возвратов, закреплённой главы, закладок, заметок, покрытия и индекса выполняются одной транзакцией; сохраняется резервная копия метаданных.

Старая цитата, пересекающая вновь распознанную границу TXT, делится на заметки по главам только после проверки точного совпадения всего текста. Текст цитаты и комментарий сохраняются. Метка версии делает перенос однократным. Перенос FB2 из старой раскладки 2 остаётся отдельным; уже перенесённые главы FB2 не делятся повторно.

Выделение цитаты между разными главами пока ограничено существующей моделью заметки, которая привязана к одной главе. Для очень длинных цитат сохраняется команда «Начать длинную цитату». Выделенные абзацы удерживаются в дереве на время выделения; обычные невидимые абзацы остаются ленивыми. Физический Android и особенности его экранной клавиатуры в этом окружении не проверялись.

Инверсия фотографий в тёмном PDF в этом пакете не менялась: вариант темы явно обозначен как инверсия страниц. Этот пакет не добавляет новые зависимости; описание выпуска — [0.23.0](RELEASE_0230.md).

## Единая нижняя панель и действия PDF

- Удалена отдельная шкала страниц загруженного участка в непрерывных режимах. Высота раскладки больше не резервирует под неё 48 пикселей; общая шкала книги остаётся внизу.
- `reader_progress_panel.dart` используется текстовой и PDF-читалкой: одинаковые дорожка, указатель, типографика, разделитель и поведение перетаскивания. В PDF сохраняются номер страницы, процент, возврат, предыдущая/следующая страница и заметки; оформление панели следует выбранной теме чтения.
- Свайп вниз, начатый на панели, сворачивает её. Вернуть можно свайпом вверх по оставшемуся элементу или кнопкой «Показать нижнюю панель». Свайпы по тексту и выделению не скрывают панель. Скрытие само по себе не выполняет переход и не меняет сохранённую позицию.
- Общая шкала использует конечную координату горизонтального жеста, а не последнее значение, успевшее попасть в перестроенный виджет. Отмена жеста сбрасывает предварительный процент; для экранного диктора сохранены действия увеличения/уменьшения.
- Меню PDF возвращает `Positioned.fill` в стек просмотрщика и использует реальные якоря выделения. Раньше PDF-просмотрщик дополнительно размещал общий toolbar в контейнере без конечной высоты, а сам toolbar требовал размеры viewport для позиционирования и обработки нажатий.
- В PDF доступны копирование, быстрое выделение четырьмя цветами, заметка с комментарием и карточка Anki. Цитата через страницы сохраняет отдельные исходные якоря на каждой странице. Запрет копирования документа учитывается; ограничения объёма цитаты/карточки сохранены.
- В настройках PDF длинные подписи ограничены шириной поля, чтобы они помещались на телефоне. Ошибка сохранения позиции остаётся видна даже при свёрнутой панели.

`reader_progress_panel_test.dart` проверяет различие вертикального и горизонтального жеста, возврат кнопкой/свайпом и сохранение позиции в трёх прокручиваемых режимах. Нативная проверка PDF выполняется при ширине 390: длительное нажатие на координате настоящего символа, нажатия на видимое меню копирования/заметки/цвета/Anki, сохранение цитат через страницы и сворачивание панели. Снимки `build/pdf-reader-controls.png` и `build/pdf-reader-selection.png` используют настоящие Onest и иконки.

После этих изменений полный набор прошёл с результатом **639 passed / 12 skipped**, включая настоящий PDFium: `.local/reader-panel-full.log`. Анализ `lib`, `test`, `integration_test` — **No issues found**: `.local/reader-panel-analyze.log`. Оба снимка PDF и обновлённый снимок текстовой читалки просмотрены. Проверка на физическом Android остаётся отдельным шагом.

## Исправления после ревью

- Временная подсветка поиска/заметки хранит номер исходной главы. Перевод в координаты сплошного текста использует именно её; в режиме одной главы чужая подсветка не отображается.
- Боковые заметки слушают смену главы. Оглавление слушает пару «глава / округлённый процент», а не каждый отчёт прокрутки. Названия глав и результат фильтрации кэшируются до изменения документа/запроса.
- TXT 5 принимает короткие заголовки с заглавной буквы только в начале абзаца. Название после номера требует разделитель, например «Глава 1. Море», чтобы не принимать «Глава 3 начиналась с того…». Параграфы восстанавливаются разделением по исходным двойным переносам; заголовок получает отдельный диапазон оформления. Парсер раскладки 4 оставлен для точного переноса ранее сохранённых координат, включая ошибочно выделенные главы.
- Отмена удаления закладки обращается к хранилищу независимо от состояния экрана и `busy`. Устаревшая загрузка списка не затирает результат более новой загрузки после отмены.
- PDF использует сохранённый последний цвет для команды «Выделить». Запись нового цвета вместе с заметкой не меняет режим текстовой читалки или другие настройки.
- F3 и кнопка следующего совпадения используют один путь: после 200 результатов автоматически запрашивается следующая порция и открывается её первое совпадение. Одновременные повторные нажатия не дублируют запрос.
- `ReadingActivity` завершает неизменяемую часть после 256 событий или 128 интервалов и продолжает запись в новую часть с общим `sessionGroup`. В памяти и при очередном чекпойнте остаётся текущая часть; старые события не удаляются. Итоги времени/символов/скорости не дублируются, список и счётчик сессий объединяют части. При временном сбое финализированная часть сохраняется для повторной записи. Используются существующие записи `reading-session:*`, экспорт и синхронизация.

Части ограничивают размер одной перезаписываемой записи. Полный экспорт дневного JSON-журнала по-прежнему собирает все его сессии; протокол восстановления дневных журналов не менялся. При длительно недоступной БД неудавшиеся части удерживаются в памяти до повторной записи, чтобы не терять события.

Новые сценарии `reader_review_regressions_test.dart`: ложные заголовки TXT и перенос из раскладки 4; подсветка после смены главы и повторного построения страницы; обновление боковых панелей; F3 на результате 201; отмена закладки после закрытия маршрута и при незавершённой загрузке; сохранение 602 событий с повтором неудавшейся записи и проверкой суммарной статистики/экспорта.

Итог после ревью: **645 passed / 12 skipped**, включая настоящий PDFium и проверку сохранения последнего цвета (`.local/reader-review-full.log`). Анализ `lib`, `test`, `integration_test` — **No issues found** (`.local/reader-review-analyze-final.log`).
