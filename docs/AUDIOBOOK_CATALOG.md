# 0.5.3 — корни библиотеки и отдельные книги

15.09.2026. Основание — скриншоты пользователя: корень `книги` ошибочно стал одной аудиокнигой с 351 треком. Требуется несколько корневых папок, содержащих отдельные аудиокниги. Аудиофайлы остаются на месте.

## Реализовано

- «Добавить папку библиотеки»: выбрать корень, увидеть найденные книги, изменить названия и исключить ненужные. Можно последовательно подключать несколько корней.
- По умолчанию группировка по папкам с аудиофайлами, включая вложенность «Автор / Книга». Папки `Disc 1`, `Диск 2`, `CD1`, `часть 1` относятся к родительской книге; также распознаются технические `audio/tracks/chapters`. Неоднозначные имена не являются гарантированным распознаванием: результат виден до подтверждения.
- Режимы «Каждый файл — отдельная книга» для одиночных M4B/MP3 и «Вся папка — одна книга». Произвольное слияние части групп и редактирование границ ещё не реализованы.
- `.pepehub` и `!Smart AudioBook Player…` исключаются из обхода. Чужие обложки и XML автоматически не импортируются и не меняются.
- Лимиты корня: 10000 аудиофайлов, 50000 элементов, глубина 32; ограничение отдельной книги — 1000 треков. Сохранение выбранных книг транзакционное, без копирования/хеширования аудиобайтов.
- Повторный выбор того же корня и режима не создаёт вторые карточки. Вложенные/пересекающиеся корни не дедуплицируются по содержимому автоматически.
- Если прежняя ошибочная общая карточка соответствует выбранному корню и все её источники представлены в новых книгах, она скрывается из библиотеки локальной отметкой. Сохранённый трек/позиция/скорость переносятся в соответствующую книгу, если у неё ещё нет собственного прогресса. Старые записи и сессии остаются в БД: историю слушания нельзя достоверно разделить задним числом.

## Папка данных

В предпросмотре есть переключатель «Сохранить снимок данных в .pepehub». При включении после подключения создаётся новый `library-<uuid>.json`: список книг, относительные названия треков, позиции и сессии выбранных книг. Абсолютные пути, URI и секреты в снимок не включаются. JSON ограничен 2 МиБ, аудиофайлы не копируются.

Это **снимок на момент подключения**, а не автоматически актуализируемая статистика. Повторное подключение с галочкой создаёт новый снимок, прежние не перезаписываются. Восстановление, ротация, обновление после каждой сессии и кэш `covers/<bookId>.*` — следующие задачи L2/L3. Старые сессии общей карточки пока остаются только в рабочей БД. SQLite остаётся основным хранилищем.

Android запрашивает сохранение чтения и доступной записи в выбранное дерево. Без права записи книги всё равно подключаются; ошибка снимка показывается отдельно. Windows не следует ссылке вместо `.pepehub`. Ни удаление оригиналов, ни запись в служебную папку другого плеера не выполняются.

## Приоритеты и проверка

Синхронизация скрыта с главного экрана; существующий код протокола сохранён. [ТЗ](AUDIOBOOK_TZ.md) и [план](AUDIOBOOK_IMPLEMENTATION_PLAN.md) пересмотрены: локальный каталог, обложки/статистика, плеер, надёжность и приёмка — до Cloudflare, устройств и Obsidian. Отмечены выполненные W0.1, W1.1, W1.4–W1.6; частичные задачи остаются открытыми.

Проверены группировка папок/дисков, отдельные файлы, исключение служебных папок, повторное подключение, перенос позиции из общей карточки, снимки JSON и отсутствие аудиокопий. Предпросмотр проверен на 360×800. Физический Android-каталог и запись SAF требуют проверки на телефоне; скриншоты 0.5.2 подтверждают прежнее воспроизведение, а не новую реализацию.
