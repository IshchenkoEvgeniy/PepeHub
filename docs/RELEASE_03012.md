PepeHub 0.30.12 — сравнение чтения, итоги года и перенос статистики.

- Статистика чтения сравнивает выбранный период с предыдущим такой же длины: время, сессии, активные дни и новое продвижение.
- Отдельная страница итогов года: лучшие книги по оценкам, самый длинный день, любимый жанр, серия дней и произведения по времени. Итоги сохраняются картинкой PNG.
- В годовой статистике появились разрезы по жанрам, авторам и сериям. Полные списки категорий создают строки по мере прокрутки.
- Общий JSON-экспорт и импорт чтения и аудио сохраняет исходную историю, заметки, цели, планы и сведения о произведениях. Повторный импорт не удваивает записи; конфликты пропускаются. Карточки библиотеки автоматически не создаются.
- Системные уведомления о целях и планах для Android и Windows: выбранное местное время, отдельный выбор целей и планов. Настройки доступны из целей, плана чтения и общих настроек.

Windows x64 и Android ARM64, сборка 92 (Android versionCode 2092). Прежние ключи подписи сохранены. По запросу пользователя тесты при выпуске повторно не запускались; проверяются сборки, версии и пакеты. Фактическая доставка уведомлений на пользовательских устройствах требует ручной проверки.
