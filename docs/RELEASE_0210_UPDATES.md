PepeHub 0.21.0, сборка 52

Добавлены обновления приложения через интернет: проверка новой версии, загрузка с прогрессом и докачкой, проверка подписи выпуска и скачанного файла.

Windows: обновление из настроек с сохранением резервной копии файлов и перезапуском. Android: загрузка APK внутри PepeHub и установка поверх текущей версии через системное подтверждение.

Первую сборку с этим механизмом нужно установить вручную один раз. Удалять прежнее приложение перед установкой не нужно — локальные книги, позиции, заметки и статистика сохраняются.

Этот репозиторий содержит только готовые сборки и подписанный список обновлений. Исходный код и ключи хранятся отдельно.
