# PepeHub 0.30.7 — серии и точность статистики

Android ARM64 · сборка 87 · versionCode 2087.

- В библиотеке появилась команда **Добавить → Серия**: общие авторы, тип и статус, вставка названий списком, автоматическая нумерация, включая дробные номера томов.
- Перед сохранением можно выбрать тома и отредактировать каждую карточку: даты, оценку, обложку, объём и прочитанное или прослушанное. Похожие карточки и повторные номера помечаются и по умолчанию не выбираются. Незаданные даты остаются пустыми.
- Выбранные тома сохраняются одной операцией. Существующую серию можно дополнить кнопкой «Добавить тома». Отдельные идентификаторы серий предотвращают смешивание циклов с одинаковыми названиями. Предпросмотр и списки работают лениво на больших каталогах.
- Ручное «Прослушано» теперь отмечается как оценка при 1× и не создаёт искусственные сессии, активные дни или выполненные дневные цели, не искажает среднюю скорость. Повторы не вычитают один участок из ручного прогресса несколько раз; последующее воспроизведение не уменьшает ранее указанную ручную часть. Значения без даты учитываются в итогах за всё время.

Ранее при подготовке изменений прошли 35 проверок статистики и 23 проверки серий и связанных сценариев, включая большие каталоги; анализ изменённых Dart-файлов — без замечаний. Интерфейс нового редактора просмотрен на ширинах 390, 768 и 1440 пикселей.

По запросу пользователя при выпуске тесты повторно не запускались: выполнена Android release-сборка со штатными проверками подписи, версии, архитектуры, выравнивания и ресурсов медиакнопок. Публикуется один полный APK и подписанный файл обновления, без Windows-сборки и дельт. Аппаратная проверка телефона не выполнялась.
