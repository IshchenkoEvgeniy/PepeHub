# PepeHub 0.30.19

- В панели «Скрытое и отсутствующее» можно удалить одну запись или несколько выбранных записей. Действие доступно в разделах «Убранные», «Файл исчез» и «Без файла».
- «Удалить только запись» убирает книгу или аудиокнигу с полки и из панели, сохраняя файлы. «Удалить вместе с файлами» также удаляет связанные файлы, включая оригиналы в подключённых папках.
- Прогресс, заметки и карточки личной библиотеки сохраняются. Повторное сканирование папки сохраняет выбор пользователя, а явное добавление исходного файла возвращает запись на полку.

Windows x64 и Android ARM64, сборка 99. Android versionCode 2099.
