# PepeHub 0.18.0 — Android

3 октября 2026 года. Версия `0.18.0+46`, ARM64 versionCode `2046`, Android 7.0+ (min SDK 24, target SDK 36). APK подписан прежним тестовым ключом и подходит для установки поверх предыдущих выпусков с сохранением данных.

- Добавлена вкладка **Меню → Рекомендации**. Создавайте свои категории и топы, добавляйте книгу сразу в несколько подборок, назначайте отдельное место в каждом топе и сохраняйте личную заметку. Поддерживаются переименование/удаление категорий, поиск в сохранённых подборках, фильтр книг без категории и экспорт данных в буфер обмена.
- Поиск по названию, автору или ISBN получает сведения из **Inventaire, Open Library и Author.Today** без ключей и аккаунтов. Можно вставить ссылку на Author.Today или Open Library. После выбора результата открывается карточка для проверки: авторы, аннотация, обложка, жанры/темы, теги, цикл, язык и доступные сведения конкретного издания. Страницы и ISBN относятся к выбранному изданию; неизвестные данные остаются пустыми.
- Вручную добавленную книгу можно дополнить через интернет. Повторное получение сведений заполняет пустые поля, сохраняя ваши исправления, заметку и места в топах. Одинаковые названия не приводят к автоматическому объединению разных книг. Ошибка одного каталога не блокирует другие, а сбой дополнительного запроса не удаляет уже полученные сведения.
- **Настройки → Источники книжных рекомендаций** позволяет включать каталоги независимо. Сохранённые текстовые сведения и подборки доступны без интернета; обложка загружается по ссылке. Новые подборки хранятся локально, их синхронизация с Obsidian в этот выпуск не входит. Существующий обмен библиотекой, журналом, обложками и заметками продолжает работать.
