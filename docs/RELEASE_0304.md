# PepeHub 0.30.4 — PDF и удобное управление статистикой

1 ноября 2026 · сборка 84 · Windows x64 и Android ARM64.

- PDF показывается без ожидания сохранения сессии и экспорта журнала чтения. Сохранённая позиция и настройки восстанавливаются несколькими параллельными запросами.
- PDF из подключённой Android-папки открывается напрямую через файловый дескриптор, если провайдер поддерживает произвольное чтение. Копировать весь файл перед первым показом больше не требуется. Для остальных провайдеров сохранён проверяемый локальный кэш.
- После одиночного и массового удаления список статистики обновляется до завершения экспорта журналов папки. Повторный вход на экран не нужен; повторные нажатия удаления защищены.
- Записи чтения и прослушивания сгруппированы по сворачиваемым дням. Заголовок показывает количество загруженных записей и общее время. Можно выбрать загруженные записи за день для удаления или экспорта.
- Фильтр «Все книги» в управлении статистикой и статистике аудиокниг заменён окном с поиском. Строки создаются по мере прокрутки даже для большого каталога.
- Календарь чтения и прослушивания использует плавную шкалу: чем больше времени за день, тем ярче ячейка относительно остальных дней месяца. Добавлена легенда.
- Экран «Медиа» стал компактнее: добавление файлов, папки и ссылки собрано в меню «+» рядом с поиском, избранное вынесено в кнопку со звездой. Карточки создаются по мере прокрутки.

Устанавливайте обновление поверх текущего PepeHub. Удалять приложение не нужно. Личная библиотека, история, цитаты и обложки сохраняются.

## Проверки

Выпуск подготовлен по сокращённому циклу проверок: полный набор тестов приложения повторно не запускался.

- 40 профильных Flutter-тестов прошли, один тест нативного музыкального декодера пропущен. Проверены каталог из 1000 книг и 1000 аудиокниг, поиск среди 2000 книг, группировка и удаление записей, календарь, кэширование PDF и прямой доступ через канал Android.
- С настоящим PDFium проверены PDF на 1500 страниц, восстановление страницы 1200 при ожидающем экспорте журнала, поиск, заметки, текстовый режим, сохранение позиции и индексация.
- Отдельно прошли два сценария медиатеки на экранах шириной 360 и 1280 пикселей; проверены снимки интерфейса.
- Анализ Dart — без замечаний. Нативный Android-код успешно компилируется.
- Проверка издателя обновлений: один тест прошёл.
- Собраны Windows release 0.30.4+84 и Android ARM64 с versionCode 2084; проверены прежний сертификат APK, архитектура, выравнивание и ресурсы медиакнопок.
- Проверены дельты с 0.30.3+83 для обеих платформ и с 0.30.2+82 для Android: восстановленные пакеты совпадают с полными по SHA-256. Дельта с предыдущего выпуска: Windows — около 6,6 МиБ, Android — около 8,1 МиБ.

Скорость открытия на физическом Android-устройстве и пользовательских PDF пока не измерялась.
