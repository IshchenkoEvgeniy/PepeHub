# PepeHub 0.30.34

* Аудиокниги: если одни и те же файлы подключены дважды (например, папка с книгой и родительская папка, где книга разбита на части 01, 02…), на общей полке остаётся полная книга, а её неначатые части не повторяются рядом. В папке, где лежат только части, они видны как раньше.
