# Как проверить PepeHub

Локальная Android-сборка — **0.14.2, сборка 42**. Её APK: `dist/PepeHub-0.14.2-android-arm64-test.apk`. [Описание изменений](RELEASE_0142.md). GitHub Release для 0.14.2 не публикуется.

Текущий выпуск для Android — **0.14.1, сборка 41**. [Изменения](RELEASE_0141.md) · [Android ARM64](https://github.com/IshchenkoEvgeniy/PepeHub/releases/download/v0.14.1/PepeHub-0.14.1-android-arm64-test.apk). Последний пакет для Windows — [0.14.0](https://github.com/IshchenkoEvgeniy/PepeHub/releases/download/v1.14.0/PepeHub-1.14.0-windows-x64.zip). В статистике чтения и аудио можно управлять исходными сессиями и событиями; сводки пересчитываются по журналу.

Ниже сохранено историческое руководство прототипа 0.4; его названия кнопок и порядок синхронизации не описывают текущий интерфейс.

## Windows

Откройте `apps/pepehub/build/windows/x64/runner/Release/pepehub.exe` либо распакуйте архив из `dist` в отдельную папку и запустите `pepehub.exe`. Папка `data` и DLL должны находиться рядом с EXE. Сборка предназначена для локальной проверки, не является установщиком.

1. **Добавить книгу** создаёт карточку с выбранным форматом, названием и автором. **Импорт книги** открывает EPUB, FB2, FB2.ZIP, TXT, Markdown, HTML, DOCX, RTF или PDF.
2. **Импорт аудио** выбирает MP3, M4B, M4A, AAC, OGG, Opus, FLAC или WAV, копирует его в данные приложения и открывает плеер. Одна карточка импорта соответствует одному файлу.
3. В плеере доступны пауза, перемотка на 15 секунд, ползунок, скорость и таймер сна. Вернуться в библиотеку можно без остановки воспроизведения; снизу остаётся мини-плеер.
4. Позиция записывается периодически и при паузе. После закрытия и повторного запуска нажмите **Слушать** у импортированной книги.
5. Время прослушивания попадает в журнал автоматически; **Записать сессию** позволяет добавить занятие вручную. В журнале текущего прототипа время хранится в UTC.
6. Значок экспорта в верхней панели сохраняет Markdown с карточками и сессиями. Его можно открыть в Obsidian. Автоматический плагин-мост ещё разрабатывается.

Исходный аудиофайл не изменяется. Рабочая база и копии аудио сохраняются в системной папке данных приложения, а не рядом с EXE. Повторный импорт того же содержимого не создаёт вторую карточку.

## Проверка синхронизации

Из корня проекта запустите `npm run dev:api`, если сервер ещё не запущен. Он слушает только ПК на порту 8787.

Откройте `.local/devices.json`. В настройках синхронизации приложения задайте:

- адрес `http://127.0.0.1:8787`;
- ID и ключ из записи `Windows`.

Нажмите **Синхронизировать**. Карточки и сессии передаются на локальный сервер; файлы аудио и позиции в этой версии не передаются. Запись `Android emulator` предназначена для второго клиента с адресом `http://10.0.2.2:8787`.

Не отправляйте файл `.local/devices.json` другим людям: он содержит ключи локального сервера. Cloudflare-токены приложению не нужны и в эти поля не вставляются.

## Границы этой сборки

Сложная вёрстка EPUB, иллюстрации, DRM, главы и многотрековые аудиокниги, R2, облачные файлы/позиции и двусторонний плагин Obsidian ещё впереди. Android-код подготовлен, но APK и проверка на телефоне не выполнены. Фоновая работа на Windows означает работу открытого приложения; закрытие процесса останавливает звук.

## Чтение EPUB в версии 0.3.0

Нажмите **Импорт книги** и выберите EPUB до 64 МБ. После копирования откроется читалка; позже её можно открыть кнопкой **Читать** у книги. Меню сверху переключает главы, стрелки снизу — абзацы. Длинный абзац прокручивается. Кнопки размера текста меняют шрифт. Глава, абзац и размер шрифта сохраняются при каждом изменении; прокрутка внутри абзаца не сохраняется. Аналогично открываются FB2, TXT, Markdown, HTML, DOCX и RTF.

Для PDF открывается просмотрщик страниц с кнопками масштаба и перехода. При повторном открытии восстанавливается страница. PDF с паролем пока отклоняется. Другие ограничения и кодировки перечислены в FORMATS.md.

При обновлении с 0.3 сначала перезапустите локальный API из обновлённых исходников (`npm run dev:api`), иначе старый сервер не примет новые значения формата. Для Cloudflare потребуется обновлённый Worker. Самостоятельного облачного развёртывания эта сборка не выполняет.

При открытии читалки аудиоплеер ставится на паузу. Время чтения в этой версии записывайте кнопкой **Записать сессию** в библиотеке. EPUB и позиция пока не передаются между устройствами. Файлы с encryption.xml отклоняются, в том числе с обфускацией встроенных шрифтов. Пределы: 5000 ZIP-записей, 256 МБ заявленного распакованного размера, 4 МБ на текстовый раздел, 32 МБ суммарно разобранного текста. Изображения и внешние ресурсы не загружаются.

При ошибке синхронизации локальная очередь остаётся на диске. Конфликт можно оставить для разбора либо принять серверную версию после просмотра. Перед отказом от локальных правок можно сделать Markdown-экспорт.
