# PepeHub 0.22.1 — продолжение звука после уведомлений

Версия **0.22.1+63**, Android ARM64 versionCode **2063** и Windows x64.

- Исправлена обработка временной потери аудиофокуса на Android: музыкальный плеер теперь обрабатывает и начало, и окончание прерывания.
- Короткие уведомления отделены от звонков. Аудиокнига временно приостанавливается и продолжает после обычного уведомления независимо от переключателя «Продолжать после звонка». Сама настройка звонков сохранена.
- Во время временной паузы музыкальный плеер сохраняет запрос аудиофокуса, чтобы Android мог сообщить о его возврате.
- Неактивный плеер больше не вмешивается в фокус звучащей книги или музыки, в том числе при закрытии прежней медиасессии.
- Повторные и быстрые прерывания, а также переходы между книгой и музыкой не должны оставлять устаревшее намерение продолжить звук.
- Ручная пауза, таймер сна, отключение наушников, смена источника и постоянная потеря фокуса отменяют автоматическое продолжение.

Устанавливайте поверх текущего приложения, не удаляя его и не очищая данные. Сертификат Android и ключ проверки обновлений сохранены.

Исправление касается мобильной обработки аудиофокуса. Полный прогон перед выпуском: **571 passed / 15 skipped**; после уточнений передачи владения профильные наборы: **51 passed / 1 skipped**; анализатор без замечаний. Физический телефон не подключён: уведомления конкретных приложений и ограничения производителя требуют проверки на устройстве.

[Причины и техническая проверка](AUDIO_NOTIFICATION_FOCUS.md).

## Публикация и проверка пакетов

25 октября 2026 года опубликован [v0.22.1-63](https://github.com/IshchenkoEvgeniy/PepeHub-Releases/releases/tag/v0.22.1-63). Windows EXE сообщает `0.22.1+63`; Android APK — `versionCode=2063`, прежний сертификат. Проверены ABI, выравнивание и ресурсы APK, подпись манифеста встроенным открытым ключом. В Windows ZIP 41 файл, без исходников, баз данных и приватных ключей.

| Пакет | Байт | SHA-256 |
|---|---:|---|
| Windows x64 ZIP | 41 599 576 | `2118221711de8c8de612a21d3b38f1b63370bd5555b1c6dfc1506206fcdb7c7a` |
| Android ARM64 APK | 56 825 753 | `e27912bc8305017650efa273733f640391db656a85dd658ac0b5c6143c66dbb0` |

Публичная приёмка с имитацией установленной `0.22.0+62` прошла: Android и Windows обнаруживают сборку 63 через стандартный URL, подпись принимается, Windows ZIP докачивается через HTTP Range и проходит проверку SHA-256 с безопасной распаковкой 41 файла. APK отдельно скачан с публичного GitHub и проверен по размеру/SHA-256. Установка приложения не запускалась, пользовательские данные не открывались.
