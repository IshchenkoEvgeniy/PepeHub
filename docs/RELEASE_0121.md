# PepeHub 0.12.1

Сборка включает оптимизацию открытия больших PDF, последовательную текстовую индексацию с отменой, ограничение памяти рендера и фиксатор масштаба/горизонтального смещения. На Android добавлены системные действия «Поделиться файлом» и «Открыть с помощью PepeHub» для поддерживаемых форматов.

Артефакты:

- [Исправленный Android ARM64 APK](../dist/PepeHub-0.12.1-android-arm64-test.apk) — 31 858 100 байт, SHA-256 `F609D4D7415BBCD19DC2820F45D676F0C7BB28970E66AC650E275F690A381CFE`. Внутри versionName `0.12.1`, versionCode `2026`, ABI `arm64-v8a`.
- [Windows x64 ZIP](../dist/PepeHub-0.12.1-windows-x64.zip) — 26 690 595 байт, SHA-256 `AF0236312E144FFB6E2CD979ECD2CB9E6DE1CB146CAAE46F71514C1FA3FB7FEF`.

APK подписан отладочным Android-сертификатом, как предыдущие тестовые сборки. Перед публикацией в магазине нужна отдельная release-подпись.

Android пересобран после обнаружения ошибки упаковки. Первый APK имел другую подпись и versionCode 26; под вторым именем был ошибочно скопирован старый APK 0.12.0. Эти два файла и их контрольные суммы заменены копиями исправленного APK. Используйте новую ссылку выше, чтобы не установить ранее скачанную копию. Windows-пакет не менялся.

Подпись исправленного APK совпадает с 0.12.0: SHA-256 сертификата `efeaed93980f9275749f27ec3b663b2f477984375ad3014e44d07c7a0048a620`. Проверены подпись, выравнивание 16 КиБ, номер версии, единственный ABI ARM64, иконки медиаплеера, Android VIEW/SEND/FileProvider в упакованном манифесте и маркеры новых функций PDF/обмена файлами в скомпилированном Dart-коде. Телефон не подключён, установка на устройство не выполнялась.

Проверены статический анализ, полный набор тестов (105 прошли, один прежний пропущен), 1500-страничный PDF, Android/Kotlin исходники и XML-манифест. Физическую проверку на телефоне и обмен через реальные файловые менеджеры следует выполнить отдельно.
