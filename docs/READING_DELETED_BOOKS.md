# Категория «Удалённые»

18 октября 2026. Опубликована [версия 0.21.8+60](https://github.com/IshchenkoEvgeniy/PepeHub-Releases/releases/tag/v0.21.8-60) для Windows и Android. Проверены подпись публичного манифеста, докачка/подготовка Windows и полное скачивание APK; [сведения о пакетах](APP_UPDATES.md).

В разделе «Книги» добавлена вкладка «Удалённые» и одноимённый пункт в меню «+». Она содержит карточки книг без доступного исходного файла; «Все», статусы чтения и блок продолжения их не показывают. Сохраняются ID, обложка, прогресс, заметки, коллекции и статистика. Статус чтения не заменяется значением deleted, запись книги не получает tombstone.

## Когда меняется категория

- Успешное «Удалить навсегда» удаляет проверенные локальные файлы/кеш и перемещает карточку в категорию.
- Обновление подключённой папки выявляет исчезнувшие книги. Кнопка обновления списка книг проверяет выбранную папку либо все подключённые папки, если выбрана вся библиотека.
- Независимая импортированная копия сохраняет доступность. При нескольких папках книга считается отсутствующей, когда исчезает последняя известная копия.
- Повторный импорт того же SHA-256 или обнаружение этого файла при обновлении папки восстанавливает ту же книгу. Имя может измениться; другое содержимое создаёт другую книгу.
- Отключение папки не означает удаление файла. Вручную скрытые книги остаются в «Убранных»; при возвращении файла их ручное скрытие сохраняется, явный повторный импорт снимает его.

У ранее скрытых карточек нельзя достоверно восстановить причину по старым одинаковым флагам. Они сохраняются в «Убранных», пока успешное обновление соответствующей папки не подтвердит отсутствие файла. Поэтому для уже удалённых до обновления книг нужно обновить папку. Старое ручное скрытие после возвращения файла сохраняется; явный импорт того же файла возвращает книгу на полку.

## Хранение и синхронизация

`reading-deleted:<bookId>` — локальный флаг metadata. Он не включён в список общих прикладных данных peer-синхронизации. Удаление файла на другом устройстве не перемещает местную карточку до фактического принятого удаления её копии.

`ReadingBookVisibility` меняет только доступность в транзакциях вызывающего кода. `ReadingRoots` хранит исторические `bookIds` для восстановления и отдельные `presentBookIds` для состояния копий. Для старых папок без нового поля присутствие предполагается до успешной проверки; отсутствие не угадывается. История и статистика по-прежнему связаны с прежним ID/хешем.

Пустой Android-снимок допускается только для доступного корня с полным списком. Потеря корня, null cursor, EXTRA_LOADING или EXTRA_ERROR прерывают сканирование до изменения библиотеки. На обычном открытии списка файловая проверка не запускается.

## Интерфейс и проверки

Карточка показывает «Файл удалён». Нажатие объясняет восстановление вместо запуска reader. В меню доступны импорт того же файла, сведения, план, коллекции и переход к папке; операции чтения/отправки отсутствующего файла не предлагаются. Заметки сохраняются в общем списке, для перехода в текст предлагается добавить файл.

- `reading_deleted_books_test.dart`: удаление/возврат прежнего ID, повторный импорт без дубликата, последняя копия среди двух папок, ручное скрытие/отключение и ошибка сканирования; экран 360×800 с текстом 1.5× и сетка Windows 1440×1000.
- Связанные проверки `reading_book_actions_test.dart` и `reading_roots_test.dart` проходят.
- Полный Flutter: **526 passed / 13 skipped**, анализ без замечаний (`reading-deleted-full.log`, `reading-deleted-analysis.log`).
- Нативные проверки: 66 для доступа/сканирования, 28 для истории, 23 для обновлятора — **117 passed**. Добавлены отказ при загружаемом списке/отсутствующем корне и успешный пустой снимок.
- Физическая проверка конкретного Android-провайдера не подменяется тестовым DocumentsProvider.
