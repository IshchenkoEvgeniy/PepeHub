# EPUB, версия 0.3.0

13 сентября 2026. Реализован первый текстовый режим чтения EPUB для этапа M1. Это не полная приёмка EPUB по ТЗ.

## Поведение

Импорт использует общий AssetStore: ограниченное потоковое копирование, SHA-256, проверка структуры, атомарная запись карточки и локального файла в SQLite, дедупликация. Разбор архива выполняется отдельным isolate через функцию, которая принимает только путь и не захватывает UI или SQLite.

Порядок глав берётся из OPF spine, метаданные из title/creator. XHTML преобразуется в текст с сохранением границ блоков. JavaScript, CSS, SVG и внешние ресурсы не выполняются и не загружаются. Содержимое архива не распаковывается в файловую систему. CRC проверяется явно; распаковка deflate ограничена по фактическому выходу.

Позиция хранится в metadata под ключом reader:SHA256 как chapter, paragraph, fontSize. Перед сменой абзаца запись ожидается; при ошибке пользователь остаётся на прежней позиции. Формат локальной базы v2 и протокол синхронизации v1 не менялись. Это локальная позиция, ещё не EPUB CFI для межустройственного обмена.

## Проверки

Четыре новых теста: порядок глав/метаданные/удаление скриптов; неподдерживаемые и слишком большие архивы; импорт/дедупликация/сохранность исходника/очистка временного файла; восстановление абзаца и сохранение навигации/шрифта через Flutter UI. Общий набор Flutter: 18 тестов прошли 13 сентября, включая прежние проверки аудио, SQLite и HTTP-синхронизации.

## Ограничения и продолжение

Один абзац на экран с прокруткой длинного текста; нет иллюстраций, CSS, интерактивных сносок, пользовательских закладок, поиска внутри книги, CFI и автоматического журнала чтения. Некоторые книги с обфускацией шрифтов отклоняются вместе с encrypted EPUB. Нет проверки на реальном Android. Следующие задачи: полноценная раскладка текста, автоматические сессии чтения, синхронизация позиции и передача файлов через R2.
