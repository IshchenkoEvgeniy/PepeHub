# PepeHub 0.10.0 — экран чтения

Экран появился в 0.10.0; актуальная версия — 0.10.1+23. Экран работает с EPUB, FB2/FB2.ZIP, TXT, Markdown, HTML, DOCX и RTF через существующий текстовый парсер. PDF сохраняет отдельный просмотрщик страниц. Версия 0.10.1 включает [библиотеку и заметки](READING_LIBRARY_010.md).

## Оформление

Кнопка «Aa» открывает настройки с образцом текста: встроенный Lora с засечками или системный шрифт без засечек; размер 14–36; межстрочный интервал 1,2–2,2; горизонтальные поля 12–48. Светлая, тёмная, сепия и системная темы. Настройки общие для текстовой читалки и сохраняются локально; тема библиотеки остаётся независимой.

Lora работает без сети, исходный файл и лицензия находятся в `assets/fonts/`. Источник: [Google Fonts / Lora](https://github.com/google/fonts/tree/main/ofl/lora), SIL Open Font License. Используется немодифицированный файл шрифта; приложение включает лицензию.

## Режимы

- Перелистывание: страницы рассчитываются по реальной ширине, высоте, шрифту и системному масштабу текста. Длинный абзац занимает несколько страниц. Свайпы, кнопки и клавиши ←/→, Page Up/Page Down перемещают по страницам.
- Прокрутка: непрерывный вертикальный текст текущей главы, без пустых полей между внутренними блоками. Кнопки перемещают примерно на высоту экрана, на границе главы — к соседней главе.
- Долгое нажатие/выделение мышью открывает меню «Выделить», «Заметка», копирование. Постоянное выделение сохраняется с точными границами исходного текста. Цвет и комментарий редактируются в заметках книги.

Раскладка рассчитывается для текущей главы; каждые восемь страниц управление возвращается циклу событий. При переходе в другую главу/закрытии старый расчёт отменяется. Поворот, размер окна и оформление вызывают перерасчёт. На очень больших главах первоначальный расчёт может занять заметное время: показывается индикатор. Изображения, таблицы, исходный CSS и сложная вёрстка EPUB пока не воспроизводятся — сохраняется текущая текстовая модель парсера.

## Навигация и позиция

Оглавление показывает все главы. Поиск регистронезависимый, по буквальной фразе во всей книге, с выдержками и подсветкой найденного фрагмента. Поиск запускается после короткой паузы ввода в отдельном isolate; показываются первые 200 совпадений, запрос можно уточнить.

Нижняя шкала показывает общую позицию по тексту всей книги и позволяет перейти к проценту. Это доля текстовых позиций, а не время чтения, количество прочитанных слов или страницы бумажного издания. Конец последней главы можно зафиксировать кнопкой «Конец книги» или переходом к 100%.

После перехода через оглавление, поиск или общую шкалу появляется кнопка возврата. Сохраняются последние 20 мест перехода, в том числе между запусками. Обычное перелистывание не засоряет эту историю.

Позиция идентифицируется главой и смещением в исходном тексте, а не номером рассчитанной страницы. Сохранение выполняется с короткой задержкой при движении и сразу при переходе, сворачивании и выходе; записи сериализованы, чтобы старый результат не затёр новый. Старые `reader:<hash>` с главой/абзацем/размером шрифта читаются автоматически. В новой записи сохраняются и совместимые поля абзаца. При смене настроек открывается страница, содержащая сохранённое место; верх страницы может начинаться раньше него.
