# PepeHub 0.30.23

* Корзина книг, понятное удаление и новый вид папок аудио
* Книги, удалённые кнопкой «Удалить только запись», оставались с пометкой
* «удалена с полки»: повторное подключение папки её не снимало, а панель
* скрытых такие книги не показывала, поэтому они пропадали везде (в папке
* 10 книг, на полке 0).
* 
* Корзина
* \- BookTrash: одна корзина для книг и аудиокниг с датой удаления и сроком
* &#x20; хранения (30 дней по умолчанию; 7/90/«пока не очищу»). Навсегда —
* &#x20; только из корзины. Старые удаления отсчитываются от обновления.
* \- Повторный выбор папки возвращает её книги из корзины; на карточке
* &#x20; папки плашка «В корзине книг этой папки: N» с кнопкой «Вернуть»,
* &#x20; счётчик папки их не учитывает.
* 
* Удаление
* \- Меню книги: «Скрыть с полки» (с «Вернуть») и «Удалить…» с выбором
* &#x20; «Только из PepeHub» / «Вместе с файлом»; книга уходит в корзину.
* \- Те же действия для выбранных книг, в том числе аудиокниг.
* \- Вкладки «Удалённые» и «Без файла» убраны с полки; вместо них ссылка
* &#x20; «Скрытые, недоступные и корзина: N».
* \- Панель «Скрытые и недоступные»: вкладки «Скрытые», «Файл не найден»,
* &#x20; «Без файла», «Корзина» (книги, аудиокниги и карточки библиотеки),
* &#x20; счётчики, открывается на первой непустой вкладке.
* \- Медиатека: «Удалить из медиатеки…» для видео, курсов и музыки
* &#x20; (файлы не трогаются, есть «Вернуть»).
* 
* Папки и статистика аудио
* \- Папки аудиокниг и статистика прослушивания в новом стиле, как у книг.
* \- Общая панель прогресса сканирования папок с отменой; сканирование,
* &#x20; идущее в фоне, видно на полке и сообщает о завершении.
* 
* Скрипты
* \- scripts/android-diagnostics: логи PepeHub и скриншот с телефона.
* \- scripts/adb-bridge: мост для проверок телефона через adb по запросам
* &#x20; из .local/adb-bridge (опасные команды отклоняются).

Windows x64 и Android ARM64, сборка 103. Android versionCode 2103.
