# PepeHub 0.14.2 · локальная сборка Android

- При подключении папки с частями `01`, `02` и так далее приложение спрашивает, считать ли их одной аудиокнигой. Порядок треков естественный; файлы остаются на месте.
- Уже добавленные части можно выделить в аудиобиблиотеке и объединить. Новая карточка сохраняет наиболее позднюю позицию, события прослушивания, заметки и закладки; старые карточки скрываются. Для подключённой папки нужно выбрать все соседние пронумерованные части.
- В библиотеках добавлен выбор нескольких карточек: долгое нажатие или кнопка выбора, затем групповые отметки статуса, избранное и объединение аудиочастей.
- В управлении статистикой можно выбирать несколько записей и удалять их с подтверждением. Журналы подключённых папок обновляются.
- Статистика чтения сохраняется в приложении при открытии книги и по ходу чтения. Для книг из подключённой папки файл в `.pepehub/reading/logs` создаётся при открытии и обновляется примерно каждые 30 секунд, а также при переходах и закрытии. В читалке есть переход к статистике с путём журнала и ручной записью. Ручные сессии тоже включаются в журнал.

Сборка: `dist/PepeHub-0.14.2-android-arm64-test.apk`, versionCode `2042`. APK и SHA-256 остаются локально; в GitHub отправляется только исходный код. GitHub Release и пакет Windows для 0.14.2 не создаются.
