# Проверка больших каталогов

Правило назначения библиотеки закреплено в `AGENTS.md` и
`PERSONAL_LIBRARY.md`: добавление только явное; статусы только `finished`,
`paused`, `abandoned`. Вкладки файлов и рекомендации независимы от архива.

## Изменения

- Архив использует один `CustomScrollView` с ленивыми `SliverList` и
  `SliverGrid`. Вложенных списков с `shrinkWrap` и полной колонки всех
  произведений больше нет. Поиск и сортировка повторяются при изменении
  каталога или условий, а не при выборе строки и раскрытии сводки.
- Каталог декодируется с кешированием по реальному значению в SQLite.
  Крупные операции JSON выполняются в отдельном изоляте. Откат транзакции
  и внешняя замена каталога инвалидируют кеш. Привязка к исходной книге
  находится через карту по ID, без перебора всех карточек для каждого меню.
- Фон библиотеки не сканирует файлы и не создаёт карточки. Обновляются
  только связанные записи архива; при таком обновлении не читаются заново
  теги всех треков, не индексируются тексты и не извлекаются обложки.
- Список аудиокниг получает один файл для открытия и одну итоговую запись
  на произведение. Расчёт длительности и позиции выполняется в SQLite,
  с выбором актуального издания. Неизвестные длительности и порядок треков
  сохраняют прежнюю семантику. Обложке достаточно первого трека.
- Для текстовой полки SQLite исключает массивы всех абзацев и разрешает
  смещение только сохранённого абзаца. Полный индекс остаётся у читалки.
- Повторные запросы обновления списка объединяются. Естественная
  сортировка использует ограниченный кеш разобранных числовых частей.
  Обложки не загружаются повторно при каждом обновлении того же виджета;
  декодированный размер ограничен.

## Воспроизводимая проверка

Из `apps/pepehub`:

```powershell
../../.tools/flutter/bin/flutter.bat test --no-pub test/library_scale_test.dart
```

Тестовый каталог: 500 текстовых книг, 500 аудиокниг, 50 001 трек
(включая альтернативное издание), 1000 самостоятельных записей архива.
Индексы содержат по 2000 смещений абзацев, позиции включают старый формат.

В локальной тестовой среде 2026-10-29 компактные запросы заняли
167–290 мс. Объём индексов, передаваемых полке, уменьшился с
5 536 330 до 86 831 байта. Архив создал 3 начальные строки вместо 1000;
проверены прокрутка, переключение на сетку и поиск последней записи.
Обе вкладки файлов сохраняют ограниченное число построенных карточек.

Дополнительно проверяются неизвестные и нулевые длительности, активное
издание, точность текстового прогресса, отсутствие автоматического
добавления файлов и сохранность старых данных при исключении черновиков.
Эти цифры характеризуют тестовую среду, а не FPS конкретного телефона.
