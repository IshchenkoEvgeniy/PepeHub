## Порядок работы и следующая очередь — 19 сентября 2026

По уточнению пользователя продолжаем улучшать исходники без промежуточных установочных сборок. Статический анализ и целевые тесты остаются частью работы. APK, Windows release и упаковка — только по отдельному запросу пользователя, одним накопленным выпуском. Синхронизация/Obsidian по-прежнему последний этап.

Очередь и текущий статус:

1. `.pepehub/reading/`: резервные снимки позиций, заметок, избранного и коллекций; восстановление без потери текущих данных. Отдельный экспорт цитат в Markdown/JSON уже реализован в исходниках.
2. **Реализовано в коде, без установочной сборки:** автоматические сессии чтения, календарь, цели, серии дней, показатели книги, раздельное новое продвижение/повтор, компактные дневные журналы. [Правила и ограничения](READING_ACTIVITY_0101.md).
3. **Реализовано в коде:** полная карточка — ручные название/авторы/серия/номер/описание/обложка/статус/даты с приоритетом над повторным сканированием.
4. **Реализовано в коде:** полный экран, зоны нажатия, двухэтапный выбор цитаты через страницы одной главы, сноски EPUB/FB2 и иллюстрации в панели главы. Остаются поиск в оглавлении, изображения в потоке текста, расширение остальных форматов и аппаратная приёмка. [Инструкция и ограничения](READING_NOTES_TOOLS_0101.md).
5. **Реализовано в коде:** теги/персонажи, совместные фильтры цвета/тега/персонажа, поиск, редактирование и экспорт отдельной книги/библиотеки в Markdown/JSON.
6. Большие библиотеки: замеры и оптимизация индексирования/поиска, отмена сканирования, понятные ошибки файлов; проверка разных размеров экрана.
7. **Реализовано в коде:** планы отдельных текстовых книг — минуты в день, цель по объёму, срок, прогноз времени/даты по собственным активным интервалам с исключением намеренных переходов. [Расчёт и ограничения](READING_PLANS_0101.md). Напоминания и резервные снимки планов остаются будущими расширениями.

## 15. Контроль прогресса и объёма

Для каждой задачи вести статус: `не начата / в работе / реализована / проверена / принята / заблокирована`. Галочка означает: работа выполнена и её программная проверка зафиксирована в VALIDATION.md. Аппаратная приёмка отмечается отдельно и не подразумевается галочкой. В отчёте фиксировать задачу, изменённые компоненты, тесты, артефакт и открытые ограничения. Проверки аппаратуры нельзя закрывать результатом эмулятора.

Контрольные поставки:

| Поставка | Состав | Демонстрация |
| --- | --- | --- |
| R1 | W0–W3 | Обновить существующую библиотеку, импортировать папку, пройти треки и встроенные главы |
| R2 | W4–W5 | Слушать в фоне, пережить звонок, вернуть случайно потерянное место, сохранить закладку, остановиться по таймеру |
| R3 | W6–W7 | Большая библиотека, внешняя папка, удобные настройки, виджет и автомобильное управление |
| R4 (после R5) | W8–W10 | Офлайн на телефоне, продолжение на ПК, конфликт двух позиций, закладка и лог в Obsidian |
| R5 (до R4) | W12 | Полностью проверенная локальная поставка с обновлением, восстановлением и отчётом |
| R6 | W11 | Расширения, принятые отдельно по платформам |

Новые версии API и новые движки выбирать после проверки актуальной официальной документации во время соответствующей задачи. В этом плане фиксируется порядок работы, а не неподтверждённая совместимость будущих зависимостей.

Календарные даты не назначаются до W0 и первой миграции W1. После R1 оценить оставшийся объём по фактической скорости выполнения и результатам испытаний, отдельно указав разработку, длительные прогоны и ожидание устройств/доступа к Cloudflare. Внешняя блокировка одной интеграции не останавливает независимые локальные задачи.
