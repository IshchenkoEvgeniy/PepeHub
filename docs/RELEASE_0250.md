# PepeHub 0.25.0 — новое оформление чтения и исправления сносок

Windows x64 и Android ARM64. Версия приложения — **0.25.0+72**,
номер Android ARM64 — **2072**.

- Компактное меню выделения с действиями «Выделить», «Заметка»,
  «Копировать» и «Ещё». Палитра появляется после нажатия «Выделить»;
  дополнительные действия доступны в отдельной панели.
- Оформление текстовой читалки разделено на вкладки «Текст», «Страница»,
  «Цвет» и «Управление». Предпросмотр показывает выбранные шрифт, размер,
  интервал и цвет. Кнопки сохранения и отмены остаются видимыми.
- PDF использует такое же окно оформления со вкладками «Страница»,
  «Цвет» и «Управление». Добавлены изменение масштаба, подгонка по ширине,
  показ всей страницы и определение белых полей, в том числе для сканов.
  Обрезка полей сохраняется отдельно для каждой книги.
- Отмена, закрытие окна и системная кнопка «Назад» возвращают прежние
  настройки. В PDF восстанавливаются также масштаб и положение страницы.
  Отложенный предпросмотр больше не применяет отменённые изменения.
- Исправлено распознавание старых сносок EPUB, включая ссылки вида
  `contentnotes0.html#n_4` и именованные якоря перед текстом примечания.
  Сноска открывается в панели с текстом, без захвата следующего примечания.
- Внутренние ссылки PDF ведут к указанному месту страницы и масштабу.
  Возврат восстанавливает прежнее положение, включая ссылки внутри одной
  страницы. Автоматическая подгонка полей не сбивает эти переходы.

Проверки: **697 тестов пройдены, 12 пропущены** по условиям окружения.
Дополнительная финальная проверка PDF и нового интерфейса — **16 из 16**.
Статический анализ — без замечаний. Проверены узкий экран, планшет,
альбомная ориентация и увеличенный системный текст; PDF проверен через PDFium.

Обновление устанавливается поверх прежней версии с сохранением данных.
Сертификат Android и ключ подписи обновлений сохранены.
Физический Android не подключён; проверка на устройстве не выполнялась.
