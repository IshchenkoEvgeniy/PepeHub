# PepeHub 0.22.2 — быстрее читалка и исправления форматов

Версия **0.22.2+64**, Windows x64 и Android ARM64 (`versionCode=2064`).

- Прокрутка обновляет позицию и отдельные элементы интерфейса, сохраняя текст и раскладку. Заметки, сноски и отметки глав используют кэши и индексы.
- Переход между результатами поиска внутри загруженного участка работает без повторной вёрстки и спиннера. Поиск и плашка длинной цитаты не меняют высоту текста; кнопки перелистывания остаются доступны.
- Изменение размеров окна объединяет перевёрстки; нижняя шкала рисует отметки глав одним слоем, вместо создания виджета для каждой главы.
- Дневное время чтения рассчитывается по числовому индексу интервалов. Повторное открытие главы больше не требует разбора всей истории. Обновления и удаления сессий учитываются без удвоения времени.
- PDF больше 100 страниц получают фоновую индексацию для статистики по знакам. Достигнутый результат сохраняется и используется после возвращения; исходный PDF доступен до окончания индексации.
- Исправлены названия глав EPUB по встроенному оглавлению, переходы по относительным внутренним ссылкам и обработка некоторых нестандартных EPUB без DRM.
- Вложенные разделы FB2 стали отдельными главами. Сохранённые позиции, цитаты, закладки и покрытие чтения переносятся на новую структуру с резервной записью.
- Настройки оформления PDF принимают режим текстовой читалки «Без пустых мест» и сохраняют его при изменении темы PDF.
- При ошибке сохранения позиции можно повторить запись, остаться в книге или явно выйти без сохранения.

**Установка:** обновляйте поверх текущего приложения, не удаляя его и не очищая данные. Прежние Android-сертификат и ключ проверки обновлений используются повторно. Первый расчёт дневного индекса большой истории может занять время.

Проверки перед сборкой: полный набор **624 passed / 12 skipped** с настоящим PDFium; после финальной правки шкалы **17 целевых проверок прошли**. Анализатор без замечаний; экран дополнительно проверен с настоящими шрифтами. На физическом Android скорость и установка отдельно не проверялись.

[Технические подробности и границы изменений](https://github.com/IshchenkoEvgeniy/PepeHub/blob/main/docs/READER_PERFORMANCE.md).

Общее выделение через абзацы, поиск «е/ё», быстрые закладки и дополнительные горячие клавиши в этот выпуск не добавлены. HTML/Markdown с соседними изображениями сохраняют известное ограничение импорта; полная браузерная вёрстка и OCR не реализованы.
