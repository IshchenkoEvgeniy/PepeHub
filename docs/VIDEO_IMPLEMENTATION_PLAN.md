# Видео — этапы и ход реализации

Спецификация: [VIDEO_SPECIFICATION.md](VIDEO_SPECIFICATION.md). Начало: 14 октября 2026.

Этот файл — постоянный трекер. `[x]` означает реализованную и проверенную указанным способом задачу; `[ ]` — незавершённую. Аппаратная приёмка и установочные сборки отмечаются отдельно. После каждого этапа обновляются результаты, проверки и следующая задача. Функции из спецификации не считаются готовыми только потому, что создан экран или модель.

## Текущий статус

15 октября добавлен общий словарь Anki: компактный ввод слов/предложений из видео, расшифровки, аудио и текстового ридера, ручное редактирование, поиск и экспорт выбранных/отфильтрованных карточек. Исправлена общая аудиопанель между разделами/подстраницами и реализована независимая папка по умолчанию для книг и аудиокниг. [Подробное описание и импорт](ANKI_AND_LIBRARY_DEFAULTS.md). Полный набор после изменений: **357 passed / 11 skipped**, статический анализ без замечаний; установочные пакеты не пересобирались.

Плеер переработан: видео занимает весь экран страницы, основные кнопки находятся поверх изображения и скрываются при просмотре, инструменты и учебные материалы открываются по запросу. Добавлены постоянная сессия с мини-плеером, нативный Android PiP и Windows мини-окно, аудиорежим с отдельным учётом, Android медиасессия/аудиофокус, таймер, масштаб/сдвиг, экспорт кадра, главы и реальные превью при перемотке. Работают редактор курса и обновление/переподключение папок с подтверждением совпадений. Быстрые заметки открываются рядом с видимым кадром: одно поле текста, автоматические привязка/время/название и параметры по запросу. Дорожки, двойные субтитры, расшифровка и подробная статистика сохранены. Windows ZIP и Android ARM64 APK `0.20.0+50` собраны до этих изменений и не пересобирались. [Описание прежней сборки](RELEASE_0200.md). Физическая приёмка Android, отрисовка Flutter texture/GPU и поведение Windows-окна на мониторах остаются открытыми; Windows SMTC ещё не реализован.

## Этап 3 — полноценное управление и организация

- [x] Полный экран с тем же контроллером/позицией, возврат по Back/Esc; Windows native channel сохраняет стиль и WINDOWPLACEMENT. Android native channel использует WindowInsetsController на API 30+ и совместимый режим на старых версиях, восстанавливает системные панели и повторно применяет режим после восстановления фокуса. Обычный Flutter immersiveSticky игнорируется при target SDK 36. Компиляция нативного кода и виджетная проверка пройдены; аппаратная приёмка отдельно ниже.
- [x] Вписать целиком / заполнить с обрезкой / растянуть; поворот на 90°. Панели помещаются на узком экране и в альбомной ориентации при увеличении текста 1,3×.
- [x] Компактные элементы поверх видео: автоматическое скрытие через 4 секунды, показ касанием/движением мыши, блокировка, меню инструментов, выдвижная панель уроков/расшифровки/заметок/глав. Заметки и поиск сохраняются при вложенных диалогах; отмена удаления доступна внутри панели.
- [x] Масштаб 1–6× и сдвиг через InteractiveViewer, pinch/колесо/трекпад, сброс, сохранение fit/поворота в текущей странице. Экспорт исходного PNG-кадра через выбор места сохранения, встроенные главы и переходы. Windows headless декодер подтверждает PNG и главы; GPU/жесты на устройствах ниже.
- [x] Реальные кадры при перетаскивании шкалы: отдельный беззвучный paused-декодер, debounce/latest-request-wins, кэш до 24 кадров/4 МиБ, освобождение через 30 секунд. Превью не перематывает основной плеер и не пишет статистику. Для HTTP(S) по умолчанию выключено, включается в инструментах. Hover-превью и замеры тяжёлых файлов остаются ниже.
- [x] Выбор встроенных аудио/subtitle-дорожек, авто/отключение, внешние SRT/WebVTT/ASS, размер/фон простого текста и задержки; настройки конкретной версии урока восстанавливаются до play. ASS сохраняет авторское оформление через libass. Нативные Windows дорожки и задержки проверены; аппаратная отрисовка отдельно ниже.
- [ ] Управление удалением импортированных файлов в UI; репозиторий уже поддерживает ревизии/tombstone и сброс выбора. Независимые шрифт/цвет/размер оригинала и перевода.
- [x] Горячие клавиши воспроизведения, ±10/1 секунда, громкости, mute, скорости, полного экрана, точного перехода, заметки и A–B; справка. Клавиши плеера не перехватывают ввод в поле поиска заметок.
- [x] Точный переход (секунды / мм:сс / ч:мм:сс, миллисекунды), проверка длительности; возврат до последних 50 ручных перемоток текущего урока. Автоматические переходы A–B не заполняют эту историю.
- [ ] Полноценные мобильные жесты; дополнительные варианты горячих клавиш и сохранение истории переходов между запусками.
- [x] Закладки/заметки к времени или диапазону: поиск, переход, редактирование, удаление с отменой, повтор сохранённого диапазона. Отдельные записи SQLite, индекс урок/версия/время, optimistic revision и tombstone; старое undo не заменяет последующие правки.
- [x] Быстрый редактор заметки с одним полем поверх отдельной области страницы: кадр остаётся над текстом/слева от него и не перекрывается редактором либо клавиатурой. Время/урок/версия фиксируются автоматически, название — из текста; параметры названия/диапазона раскрываются отдельно. Сохранены цитаты, ручные названия, поиск/вкладка/прокрутка учебной панели, отмена закрытия и текст при ошибке сохранения. Проверены имитация клавиатуры, поворот, единственный декодер, пустая закладка и конфликт ревизий.
- [x] Мини-плеер внутри приложения: перемещение, пауза/открытие/закрытие, те же декодер/позиция/дорожки/таймер; внешние субтитры сохраняются. Виджетная проверка переходов и единственного декодера.
- [x] Android PiP: capabilities, вход/auto-enter, аспект, системные действия ±10 секунд/play/pause, скрытие Flutter-кнопок, lifecycle. Windows мини-окно: размер по DPI, поверх окон, перенос/resize, восстановление стиля/размещения; полный экран корректно выходит из мини-окна. Код обеих платформ компилируется; физическая приёмка ниже.
- [x] Аудиорежим отключает video track, поддерживает фон и отдельную статистику. Android использует общую audio_service-медиасессию книг/видео, metadata/позицию/очередь, кнопки и seek, аудиофокус speech, прерывания/отключение наушников. Передача звука между книгой и видео исключает одновременное воспроизведение. Если медиаслужба не запустилась, фоновый аудиорежим не включается.
- [x] Таймер 1–1440 минут либо до конца текущего урока; отмена/замена, защита от старого callback, остановка на конце и сброс end-таймера при смене урока. Экран не засыпает при видимом воспроизведении.
- [ ] Windows SMTC и системный аудиофокус/уведомления об отключении устройств; восстановление фонового аудио после уничтожения Android-процесса.
- [ ] Карточки/статусы/коллекции/теги/сортировки и материалы урока.
- [x] Ручной порядок после импорта, названия курса/уроков и назначение модулей; проверка устаревшего редактора. Стабильные ID, версии, прогресс, заметки и порядок сохраняются. Перетаскивание и сохранение проверены на узком экране.
- [x] Обновление/отключение/переподключение корня, новые/недоступные/изменённые файлы, сохранение ручной структуры. Быстрый SHA-256 fingerprint образцов + размер/mtime, повторная проверка перед применением/открытием. Подтверждение кандидатов сохраняет ID/версию; неоднозначные совпадения не выбираются автоматически. Изменённый файл получает новую mediaVersion; старая история остаётся. Повторное подключение того же корня открывает обновление.
- [ ] Полное хеширование файлов по запросу, замеры больших папок и физическая SAF-приёмка; частичный fingerprint не доказывает равенство всего содержимого.
- [ ] Альтернативные источники и замена ссылки без потери истории.

Выход: повседневный видеоплеер соответствует требованиям раздела 4 спецификации.

### 14 октября 2026 — подробная статистика и прогресс курса

Расширены анализатор, хранилище и интерфейс статистики. Короткие паузы сохраняют занятие, но не добавляют активное время; после паузы более пяти минут контроллер использует новый session ID. Старые интервалы с одним ID и длинным разрывом тоже разделяются при расчёте. В событиях теперь сохраняются session ID и время контроллера. Несколько быстрых команд перехода к следующему уроку рассчитываются последовательно от результата предыдущей команды.

На странице статистики доступны активное/прошедшее время и перерывы сессии, впервые/повторы, даты первого/последнего просмотра, календарь с переключением месяцев и раскрытием дня, цели и серии. Сравнение текущей/прошлой недели обрезает оба периода по одинаковому дню недели и времени; при нулевой базе процент отсутствует. Цели относятся ко всей видеобиблиотеке даже при просмотре отдельного курса; серия/сравнение относятся к выбранным урокам.

История интервалов использует SQL keyset-пагинацию `(startEpochMs, id)`, включая совпадающие времена и рост текущего checkpoint. Новые epoch-поля добавлены обратно совместимо; старые записи читаются через вычисляемый SQL timestamp. Индексы создаются без изменения схемы старых книг/аудио. Сессии рассчитываются из исходных интервалов в isolate и пока загружаются вместе с точной аналитикой, а не независимо из постоянного session-агрегата.

Карта покрытия строится по реальным диапазонам и числу проходов, ограниченным длительностью текущей версии урока. Прогресс курса — сумма уникального покрытия / сумма длительностей. Ручная отметка увеличивает количество завершённых уроков, но не процент просмотренного. `video_learning` хранит самостоятельные даты ручного завершения, понимания и первого достижения порога; состояния привязаны к версии медиа и обходят книжный outbox. Текущий автоматический статус всегда вычисляется по текущему покрытию и текущему порогу; историческая дата сохраняет порог, действовавший при её фиксации.

При изменении отметок в статистике и возврате карточка курса обновляет прогресс и статусы. Длительности пока определяются при открытии уроков: для ещё не открытых неизвестных файлов общий процент показывается как неизвестный, а известный объём отображается отдельно. Независимая фоновая проверка длительностей курса остаётся следующей задачей.

Запоздалая позиция перед seek не создаёт дублирующий проход. Повторные просмотры сохраняются через тот же sampler/checkpoint, а возвраты к A и паузы не создают просмотренного объёма. Проверяется длительность, актуальность урока и ревизия заметки; tombstone не воскрешается устаревшей правкой, старое undo не заменяет новый текст. Даты создания сохраняются при изменении. Данные заметки не меняют статистику просмотра и не попадают в книжный outbox. Они пока находятся только в локальной SQLite.
