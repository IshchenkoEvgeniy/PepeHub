# PepeHub 0.24.4 — исправление чёрного экрана читалки Android

Windows x64 и Android ARM64. Версия приложения — **0.24.4+71**,
номер Android ARM64 — **2071**.

- Исправлен чёрный экран текста при открытии книги, когда Android не сообщает
  корректные размеры дисплея. Панели работали, но область книги получала нулевой
  размер. Теперь используются размеры окна или последние корректные размеры.
- Сохранена стабильность страниц при скрытии и возвращении интерфейса.
- Добавлена защита от нулевых, неполных и нечисловых размеров дисплея,
  восстановление после нулевого размера окна при запуске и учёт поворота экрана.
- Разметка боковых панелей определяется реальной шириной окна.

Сценарий чёрного экрана воспроизведён автоматическим тестом до исправления.
Проверки после исправления проверяют наличие видимого текста во всех четырёх
режимах и сохранение разметки при переходе в полный экран.

Полный набор тестов выпуска: **673 пройдены, 19 пропущены** по условиям окружения.
Статический анализ — без замечаний.

Обновление устанавливается поверх прежней версии с сохранением данных.
Сертификат Android и ключ подписи обновлений сохранены.
Физический Android не подключён; проверка на устройстве не выполнялась.
