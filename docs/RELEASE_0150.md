# PepeHub 0.15.0 · Android

Выпуск обновляет оформление всех трёх разделов и добавляет обмен метаданными библиотеки с Obsidian.

- Новый интерфейс по концепту «полка.»: графитовая палитра, фиолетовые акценты, Manrope, карточки статистики и адаптивная коллекция. Светлая, тёмная и системная темы сохраняются.
- Третий раздел «Библиотека» автоматически получает книги и аудиокниги из Obsidian. Доступны поиск по названию, автору и серии, фильтры формата и статуса, сортировка, список и сетка.
- Полный редактор метаданных сохраняет основные и пользовательские YAML-свойства, включая пустые значения. Изменения доставляются через отдельную очередь; ошибки и конфликты отображаются в карточке.
- Локальные книги добавляются в Obsidian отдельной командой. Подключение библиотеки не выгружает существующие книги автоматически. Для обмена нужны обновлённый Habit Timer и Cloudflare Companion; [инструкция](OBSIDIAN_LIBRARY.md).
- Годовую цель можно задать локально. Статистика использует реальные статусы и прогресс; отсутствующие данные не заменяются примерными значениями.
- Сохранены чтение, аудиоплеер, позиции, заметки, статистика, избранное, коллекции и объединение аудиочастей из 0.14.2.

## Установка

APK предназначен для ARM64-устройств с Android 7.0 или новее. Версия приложения — `0.15.0`, versionCode ARM64 — `2043`, package ID — `app.pepehub.pepehub`.

Используется прежний локальный тестовый ключ. Установите APK поверх предыдущей версии; удалять приложение для обновления не требуется. Этот пакет предназначен для ручной установки, публикация в Google Play не выполняется.

Пользовательские файлы, база библиотеки, настройки подключения и токены не входят в APK. Метаданные Obsidian передаются через подключённый пользователем сервер; файлы книг и аудио этим обменом не переносятся. Локальные ссылки Obsidian на обложки отображаются резервной иллюстрацией.
