## Ограничения проверки

Нативный аудиотест использует WAV собственного генератора. Импорт MP3/M4B/M4A проверен на заголовках и логике копирования; реальная матрица кодеков/глав требует дополнительных файлов и тестов. Успешная компиляция не подтверждает все сценарии воспроизведения.

Android APK, телефон, фоновые ограничения, экран блокировки, гарнитура и звонки не проверены. Эти сценарии нельзя считать готовыми только по наличию audio_service в проекте.

При нативном WAV-тесте libmpv выдаёт диагностические сообщения о свойстве osc и файловом кеше; тест воспроизведения и сохранения при этом проходит. Влияние на будущий сетевой плеер ещё не оценено.

Нагрузочные показатели из ТЗ не измерялись. Cloudflare workerd/D1, R2, EPUB и автоматический плагин Obsidian не проверялись и не разворачивались. Все предметные проверки использовали синтетические данные; основная библиотека пользователя не мигрировалась.

Windows ZIP — сборка для локальной проверки. Для публичного выпуска остаются упаковка установщика, подпись, проверка зависимостей/лицензий и расширенная приёмка по ТЗ.
