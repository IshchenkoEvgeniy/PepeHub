PepeHub 0.21.7 — удаление карточек уже отсутствующих книг

- Исправлена ошибка Android «Failed to determine … Missing file», возникавшая при удалении книги, файл которой уже удалён через файловый менеджер или синхронизацию.
- Приложение подтверждает отсутствие файла по доступной папке и завершает очистку карточки и кеша чтения. Прогресс, заметки и статистика сохраняются.
- Временно недоступный накопитель, неполная загрузка списка папки и ошибки доступа не считаются удалением файла. При таких ошибках карточка сохраняется и показывается понятное сообщение.
- Повторное удаление уже исчезнувшего файла не требует лишнего разрешения на запись, если папку можно прочитать.

Обновление устанавливается поверх текущего PepeHub. Удалять приложение не нужно.
