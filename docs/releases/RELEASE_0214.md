PepeHub 0.21.4 — исправление установки обновлений Android

- Исправлено ошибочное сообщение «Подпись APK отличается от установленного приложения» на Android 9/10: обновлятор теперь запрашивает сертификаты с учётом поведения этих версий Android.
- Если сведения о подписи недоступны, показывается точная причина вместо сообщения о другом ключе.
- APK с действительно отличающейся подписью по-прежнему отклоняется. Ключ подписи PepeHub сохранён.

Если установленная версия 0.21.2 или 0.21.3 блокирует установку этим сообщением, один раз скачайте APK через браузер и откройте его из загрузок. Подтвердите обновление существующего PepeHub. После этого будет работать исправленная проверка.

Приложение удалять не нужно. Установка поверх текущей версии сохраняет библиотеку, настройки, заметки и статистику.
