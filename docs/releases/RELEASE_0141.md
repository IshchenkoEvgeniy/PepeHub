# PepeHub 0.14.1 · Android

- Восстановлена непрерывная прокрутка всей книги: границы глав не прерывают чтение.
- Большие книги показывают первые страницы до завершения разметки всей книги. Следующие страницы подготавливаются заранее во время чтения; счётчик страниц отмечает `+`, пока итог ещё не рассчитан.
- В управлении статистикой добавлены поиск по книге, дате и типу записи; фильтры по книге, типу и периоду; сортировка по времени; итог видимых записей по времени и знакам.
- Видимые записи чтения или прослушивания можно скопировать в CSV для дальнейшей обработки.
- Ручную сессию чтения теперь можно изменить через форму с выбором книги, даты и длительности. Редактор всех полей JSON сохранён в меню записи.

Выпуск содержит только Android ARM64 APK: `dist/PepeHub-0.14.1-android-arm64-test.apk`, versionCode `2041`. Рядом лежит файл SHA-256. Подпись совместима с предыдущими тестовыми APK. Windows пакет 0.14.1 не выпускается.
