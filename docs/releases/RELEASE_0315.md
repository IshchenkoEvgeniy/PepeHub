# PepeHub 0.31.5

* Полноэкранного режима больше нет. Текст всегда на весь экран, тап по центру показывает шапку и низ поверх страницы. Системные панели не переключаются, размер страницы не меняется, поэтому страница больше не перескакивает. Тест это проверяет: показ панелей не пересоздаёт и не сдвигает страницу.
* Шапка: ← назад, название, поиск, ⋮. Низ: прогресс по книге и четыре кнопки — Оглавление, Оформление, Заметки, Закладка. Строку «сегодня N мин» я убрал. Под текстом теперь тихая строка «глава · 12 из 40».
* «К главе», «Вернуться после ссылки» и ↶ заменены одной кнопкой «Вернуться». Она маленькая, появляется после перехода (оглавление, поиск, ссылка, закладка) и исчезает через 6 секунд. В нижней панели она остаётся, пока не воспользуешься. Закрепление главы удалено целиком.
* Картинки: размер берётся из самого файла, по пропорциям; маленькие не растягиваются. В режиме страниц картинка встаёт в страницу вместе с текстом, и подпись не отрывается. Тап по центру картинки открывает её на весь экран с увеличением, тап по краю листает дальше. В тёмной теме белый фон картинок приглушён.
* Врезки оформлены тонкой линией слева, без заливки и скруглений.
* Режимы: осталось два — «Страницы» и «Прокрутка», у прокрутки есть переключатель «Каждая глава отдельно». «Непрерывно» и «Без пустых мест» удалены. Твой сохранённый режим «Непрерывно» откроется как прокрутка. Ползунок «Высота страницы» тоже удалён.
* Окно оформления: вместо четырёх вкладок одна лёгкая шторка поверх книги, изменения сразу видны на странице. В ней:
* размер текста;
* шрифты плитками, каждый показан своим начертанием;
* цвет страницы кружками;
* режим чтения;
* интервал, поля и выравнивание.
* Остальное спрятано в «Управление и экран». Закрытие шторки сохраняет выбор, «Отменить» возвращает как было.

Windows x64 и Android ARM64, сборка 122. Android versionCode 2122.
