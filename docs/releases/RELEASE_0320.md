# PepeHub 0.32.0

**Медиа: превью видео, сортировка, автопоиск и порядок с удалёнными файлами**

* Превью: в списке «Медиа» у каждого видео и курса теперь кадр из ролика, а у уроков курса — кадр с номером урока. На превью видео видна длительность, на превью курса — число уроков. Кадры появляются по мере прокрутки и сохраняются, поэтому при следующем открытии показываются сразу.
* Сортировка: кнопка рядом со звёздочкой. Недавно смотрели, недавно или давно добавленные, по названию А–Я и Я–А, сначала длинные. Выбор запоминается и работает в режимах «Список», «Папки» и «Плейлисты».
* Автопоиск: «+» → «Найти видео автоматически» → «Добавлять новые видео автоматически». При открытии «Медиа» PepeHub сам ищет в выбранных местах и добавляет новые серии, курсы, фильмы и подборки. Камера, мессенджеры, записи экрана, короткие ролики и скрытые группы добавляются только вручную. Если группа не нужна, скройте её на экране поиска. Для поиска по всему устройству один раз разрешите доступ к видео через ручной поиск.
* Удалённые с устройства видео больше не остаются в списке. Прогресс и заметки к ним сохраняются: если файл вернётся (например, вставите карту памяти), видео снова появится само.

Windows x64 и Android ARM64, сборка 135. Android versionCode 2135.
