Исправления обновления Android:

- Если разрешения установки нет, кнопка установки открывает настройки Android. После выдачи разрешения и возврата в PepeHub установка продолжается автоматически.
- APK передаётся системному установщику с доступом на чтение и идентификатором вызывающего приложения; предусмотрен совместимый запасной вызов.
- Проверка APK и вызов Android ограничены по времени. При ошибке остаётся возможность повторить установку без нового скачивания.
- На экране виден этап проверки, ошибки можно скопировать. Добавлены скачивание APK через браузер и прямая ссылка для ручной установки поверх приложения.
- После перезапуска и повторной проверки обновлений используется уже скачанный проверенный пакет.

Книги, история, заметки и настройки сохраняются. Удалять приложение перед установкой не нужно.
