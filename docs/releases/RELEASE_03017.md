PepeHub 0.30.17 — отдельная папка личной библиотеки для Windows и Android.

- В «Настройки → Экспорт и резервные копии» можно выбрать папку библиотеки. В ней хранятся карточки, состав серий, коллекции, цитаты, заметки, история и сохранённые обложки. Можно выбрать готовую PepeHub-library или её родительскую папку.
- Данные автоматически сохраняются и перечитываются из выбранной папки. Для переноса на другое устройство достаточно скопировать всю папку или передавать её файловым синхронизатором. Исходные книги и аудиотреки хранятся отдельно.
- Изменение карточки не переписывает весь архив. Длительная запись не блокирует общую базу приложения, а правки, сделанные во время сохранения, учитываются при повторной записи.
- При недоступной папке библиотека остаётся доступна из локальной рабочей копии. Папку можно переместить; перед отключением сохраняются последние изменения. Ошибки записи не удаляют данные на устройстве.
- При подключении сохраняются карточки, цитаты, история, обложки, корзина и непрочитанные тома серий. Наличие исходных файлов само по себе не добавляет произведения в личную библиотеку.
- Повреждённые данные и повторяющиеся ID журнала отклоняются до замены локальной библиотеки. Повреждённая локальная обложка восстанавливается из проверенной копии в папке.

Windows x64 и Android ARM64, сборка 97; Android versionCode 2097. Обе release-сборки собраны; версии, прежний сертификат APK, ARM64 ABI, выравнивание и ресурсы медиакнопок проверены. Предыдущие ключи подписи сохранены. До подготовки релиза прошли 75 профильных проверок и полный анализ Flutter. При выпуске полный набор тестов повторно не запускался. Установка на физический телефон отдельно не проверялась.
