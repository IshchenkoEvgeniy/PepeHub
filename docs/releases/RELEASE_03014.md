PepeHub 0.30.14 — статусы и данные томов цикла.

- При вводе или выборе цикла редактор сразу предлагает дополнительный статус «Не прочитана» для книги и «Не прослушана» для аудиокниги. Такой том можно сохранить через обычное добавление в библиотеку.
- Книга с указанным циклом присоединяется к его существующей группе. Уже сохранённые карточки без внутренней привязки восстанавливают её при открытии библиотеки, если совпадение однозначно. Карточки, обложки, цитаты и история сохраняются. Циклы с одинаковыми названиями и разными ID остаются раздельными.
- Под полем цикла появляется предложение взять общие данные из других его книг: авторов, чтецов, жанры, язык, издательство и теги. Можно выбрать поля перед применением. Уже заполненные поля по умолчанию не отмечены; расходящиеся сведения не предлагаются.

Windows x64 и Android ARM64, сборка 94 (Android versionCode 2094). Прошли 11 адресных проверок, включая редакторы книги и аудиокниги и каталог из 2000 томов. Полный набор тестов при выпуске не запускался. Версии, подписи и пакеты проверяются; прежние ключи подписи сохранены.
