# PepeHub 0.30.18

- В подключённой папке библиотеки карточки сохраняются под названиями произведений. Серии получают отдельные подпапки, а в архив попадают карточки личной библиотеки и тома серий. При обновлении прежний каталог сохраняется для восстановления.
- В меню карточки можно сразу удалить её с сохранением файлов или подтвердить удаление карточки вместе с файлами. Оба действия доступны и для карточек в корзине. Локальная обложка удаляется, когда она больше не нужна другим карточкам.
- При добавлении отдельной текстовой книги PepeHub открывает исходный файл по сохранённому пути. Если в настройках выбрана «Папка добавленных книг», книга записывается сразу туда. Уже находящийся там файл используется повторно.
- На Android выбор книги запоминает доступ к исходному документу, если файловый провайдер выдаёт постоянное разрешение. Для PDF, доступных только как поток, просмотрщик может использовать временный кеш.

Windows x64 и Android ARM64, сборка 98. Android versionCode 2098.
