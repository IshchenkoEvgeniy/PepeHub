# PepeHub 0.27.0 — самостоятельная личная библиотека

Windows x64 и Android ARM64. Версия приложения — **0.27.0+75**,
номер Android ARM64 — **2075**.

- Библиотека стала самостоятельным локальным каталогом. Для создания
  карточки, выбора обложки, оценки и впечатлений подключение Obsidian
  больше не требуется. Можно добавить прочитанную книгу без файла и
  оставить неизвестную дату окончания пустой.
- Основная полка показывает завершённые книги и аудиокниги. Добавлены
  сортировка по дате завершения и фильтр по году. Не заданная годовая
  цель занимает компактный блок.
- Рекомендации и подборка «Хочу прочитать» остаются отдельным разделом.
  Действие «Уже прочитано / прослушано» переносит сведения в карточку
  библиотеки с сохранением связи и существующих подборок.
- Obsidian вынесен в «Импорт и экспорт»: новые локальные карточки
  экспортируются по выбору пользователя, связанные обновляются при
  обмене. Одновременные изменения можно сравнить и выбрать версию.
  Локальное сохранение не ждёт сеть.
- Закешированные карточки прежних подключений переносятся в личную
  библиотеку с сохранением исходных данных и очередей. Незавершённые
  карточки доступны в разборе импорта: их можно перенести в рекомендации
  или сохранить завершёнными. На основной полке они не отображаются.
- Отключение Obsidian и удаление удалённой карточки сохраняют локальную
  книгу. Журнал и цитаты доступны локально; отражения локальных источников
  не добавляются повторно. Обложки выбираются офлайн и передаются отдельно
  при включённом обмене обложками.
- Завершённые локальные книги подхватываются в каталог. Для аудио
  учитывается окончание последнего трека издания. Защищены явная очистка
  полей и сохранение устаревшей формы поверх более новых изменений.

Схема SQLite остаётся **4**; новый каталог использует существующее
транзакционное хранилище metadata. Исходные хранилища Obsidian не удаляются.
Подробнее: `docs/PERSONAL_LIBRARY.md`.

Статический анализ Flutter и сборка Windows успешны. Интерфейс и перенос
незавершённой карточки вручную проверены на отдельной демонстрационной базе.
**Тесты при подготовке выпуска не запускались по указанию пользователя.**
На физическом Android и с рабочим хранилищем Obsidian изменения не проверялись.

Сертификат Android и ключ подписи обновлений сохранены. Обновление использует
полные пакеты APK/ZIP; дельта-обновления в этот выпуск не входят.
