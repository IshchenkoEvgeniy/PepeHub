# PepeHub 0.30.0 — книжный календарь и итоги года

30 октября 2026 · сборка 80 · Windows x64 и Android ARM64.

- В меню аудиокниги добавлены «Убрать из списка» и «Удалить файлы аудиокниги». Убранные произведения можно вернуть через меню «+» → «Убранные аудиокниги». Скрытие сохраняется после обновления подключённой папки.
- При удалении аудиофайлов сохраняются карточка библиотеки, обложка, прогресс, заметки и история. Перед удалением проверяются все файлы; общие с другой аудиокнигой файлы не удаляются. Android запрашивает доступ на запись к папке, если его не хватает.
- Вместо «Год по дням» появился книжный календарь: обложки, выбор месяца, время за день и список произведений выбранного дня. Завершения без таймера отмечаются без приписывания времени.
- История чтения и прослушивания сгруппирована по дням и произведениям: показываются суммарное время и дневной прогресс. Отдельные записи доступны для просмотра и редактирования. В карточке показан общий прогресс книги.
- Даты начала, завершения и повторных прочтений отображаются кратко, без технического времени и часовых поясов.
- В статистике добавлена вкладка «Годовая статистика»: выбор года и типа книг, цель, графики завершённых книг и времени по месяцам, средняя оценка и её распределение, страницы, активные дни и список завершённых произведений с обложками.
- Сводки не дублируют связанную локальную и импортированную историю. Неизвестная дата завершения не заменяется текущей датой. Перечитывания сохраняются в истории.
- Списки журнала, годовой статистики и убранных книг создаются лениво. Сохраняются оптимизации больших каталогов из предыдущего выпуска.

Устанавливайте обновление поверх текущего PepeHub. Удалять приложение не нужно. Полные пакеты и проверенные дельта-обновления доступны для обеих платформ.

## Проверки

- Flutter: 778 прошли, 19 пропущены; в том числе календарь и годовая статистика на узком экране с увеличенным шрифтом, дневная история, удаление аудиокниг и большой каталог из 1000 произведений и 50 001 трека.
- Android JVM/Robolectric: 139 прошли, включая 78 проверок доступа к файлам книг и аудиокниг на API 26, 28 и 35.
- Node: 56 прошли; проверка TypeScript и анализ Dart — без замечаний.
- Тестовые сценарии старого экрана библиотеки и обмена заметками приведены к текущим правилам личного архива и ленивому интерфейсу.

Автоматические проверки не заменяют установку и проверку на физическом телефоне.
