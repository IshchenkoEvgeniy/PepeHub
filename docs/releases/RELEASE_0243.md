# PepeHub 0.24.3 — стабильные страницы при скрытии системных панелей Android

Windows x64 и Android ARM64. Версия приложения — **0.24.3+70**,
номер Android ARM64 — **2070**.

- Исправлен повторный пересчёт страниц при переходе в полный экран на Android,
  где скрытие системных панелей меняет размеры окна Flutter. Размер страницы
  определяется дисплеем; сохраняются переносы, границы страниц и положение текста.
- Исправление действует в режимах непрерывного чтения, перелистывания,
  чтения без пустых мест и по главам, в обеих ориентациях экрана.
- Кнопки перелистывания остаются в видимой области, когда системные панели
  перекрывают часть страницы. Настройки высоты страницы и ширины колонки сохранены.
- Добавлены проверки с изменением фактического размера окна после прокрутки
  и перехода на следующую страницу. До исправления этот сценарий пересоздавал
  страницы; после исправления сохраняются измеренная разметка и позиция.

Обновление устанавливается поверх предыдущей версии с сохранением данных.
Сертификат Android и ключ подписи ленты обновлений остаются прежними.

Проверки: 666 Flutter-тестов пройдены по общему прогону и повторной проверке
16 сценариев меню после обновления устаревших UI-тестов; 19 проверок пропущены
по условиям окружения. Все 55 серверных тестов пройдены, Dart-анализ и TypeScript —
без замечаний.

Проверки на физическом Android не выполнялись: устройство не подключено.
