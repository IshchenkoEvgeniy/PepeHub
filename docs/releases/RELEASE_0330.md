# PepeHub 0.33.0

**Медиа: виды оформления, выделение нескольких видео, переименование и удаление**

* Виды: кнопка рядом с сортировкой. «Список», «Компактно» (узкие строки, больше видео на экране), «Плитка» (сетка превью: на телефоне 2 колонки, на широком экране больше) и «Крупные карточки». Выбор запоминается и действует и в курсах.
* Сортировка папок: в режиме «Папки» сами папки тоже упорядочены — по названию, по общей длительности или по первому видео (например, сверху папка с самым свежим).
* Сортировка внутри курса: порядок курса, по названию, сначала длинные или короткие, недавно смотрели, сначала непросмотренные.
* Меню «⋮» у видео, курса и урока: переименовать, сведения (путь, размер, длительность), в плейлист, отметить просмотренным или снять отметку, убрать из медиатеки (с кнопкой «Вернуть») и «Удалить с устройства» — файлы действительно удаляются после подтверждения. На Android для файлов из медиатеки система покажет свой диалог.
* Выделение: долгое нажатие на видео или урок. Дальше касаниями добавляйте и убирайте, сверху «Выбрать все», «В плейлист» и меню с избранным, отметкой «просмотрено», удалением и «Объединить в курс…» — разрозненные видео собираются в один курс с сохранением прогресса и заметок. «Назад» снимает выделение.
* Исправлено: на Android «Добавить папку» в поиске видео не получала выбранную папку. Новые папки подключаются с правом записи, чтобы файлы из них можно было удалять.

Windows x64 и Android ARM64, сборка 136. Android versionCode 2136.
