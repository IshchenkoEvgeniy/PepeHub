PepeHub 0.21.5 — управление историей файлов синхронизации

- Сохранение резервных версий теперь по умолчанию выключено, в том числе для уже подключённых общих папок. При выключенной истории подтверждённое удаление выполняется без резервной версии.
- Если история нужна, её можно включить отдельно для каждой папки на каждом устройстве: «Устройства и общие папки» → «История и очистка».
- Версии хранятся в служебной папке .pepehub/p2p/versions. Старые .pepehub-version-* переносятся туда при первой проверке папки или открытии экрана истории; выключение истории сохраняет уже созданные копии.
- Для включённой истории доступны ограничения срока и объёма. По умолчанию — 30 дней и 500 МБ; самые старые копии удаляются первыми.
- Новый экран показывает количество копий и занятое место. Очистка требует подтверждения и затрагивает только сохранённые версии.
- При отказе финальной замены восстанавливается исходный файл. Очистка истории не затрагивает данные отката во время передачи. Дополнена защита изменений, сделанных во время замены.

Некоторые Android-провайдеры не поддерживают перемещение документов. В этом случае старые копии сохраняются на месте и отображается причина; их можно явно очистить на экране истории.

Устанавливайте обновление поверх текущего PepeHub. Удалять приложение не нужно.
