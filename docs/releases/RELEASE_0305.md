# PepeHub 0.30.5 — компактные серии и папка добавленных книг

4 ноября 2026 · сборка 85 · Windows x64 и Android ARM64.

- Серии в личной библиотеке сворачиваются в одну строку или карточку с количеством книг и аудиокниг. По нажатию раскрываются тома по порядку. Группировку можно отключить кнопкой рядом с сортировкой; выбор сохраняется между запусками. Поиск и фильтры находят книги внутри свёрнутых серий.
- «Сбросить фильтры» очищает и поле поиска, и применённый запрос, включая ожидающее обновление после ввода текста.
- В форме книги поддерживаются несколько чтецов: отдельные имена, подсказки и удаление каждого имени. Чтецы отображаются в карточке произведения и доступны для поиска. Старые значения, сохранённые одной строкой, продолжают открываться. Сведения об издании собраны в дополнительных свойствах.
- Подсказки авторов, жанров, серий, чтецов и других полей формируются из текущей личной библиотеки. Значения только из корзины, старых служебных заготовок и очереди файлов больше не предлагаются. После восстановления книги её значения возвращаются в подсказки.
- Поиск книги в управлении статистикой предлагает произведения, у которых есть записи на выбранной вкладке. Учитываются автоматические, ручные и старые сессии. После удаления последней записи книга исчезает из выбора.
- Для текстовых книг, добавляемых отдельными файлами, можно выбрать папку: «Настройки → Файлы и библиотека → Папка добавленных книг». Новые файлы копируются туда автоматически. Ранее добавленные книги можно скопировать отдельной командой вместе с журналами чтения в `.pepehub`; исходники, идентификаторы, прогресс и история сохраняются. Совпадающие названия не перезаписывают друг друга. Настройка не меняет импорт аудиокниг и подключённые папки.
- В исходниках сохранён отдельный интерактивный дизайн-прототип `design/concepts/2026-11-01-taste`; он не заменяет интерфейс Flutter-приложения.

Наличие файла по-прежнему не добавляет произведение в личную библиотеку автоматически. Устанавливайте обновление поверх текущего PepeHub без очистки данных.
