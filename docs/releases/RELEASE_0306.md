# PepeHub 0.30.6 — Android

Исправлен учёт вручную указанного поля «Прослушано» в метаданных аудиокниги. Часы и минуты учитываются в общей, годовой и подробной статистике прослушивания; время из журнала плеера повторно не прибавляется. Общая статистика обновляется после сохранения карточки.

Для календаря используется дата завершения, а при её отсутствии — дата начала. Автоматический прогресс плеера не превращается в дополнительные ручные записи. Исходная история и карточки сохраняются.

Выпуск только для Android ARM64, версия 0.30.6+86, Android versionCode 2086. Публикуется полный APK без дельт.

При подготовке исправления ранее прошли 20 Flutter-тестов, включая каталог из 1000 книг и 1000 аудиокниг; анализ изменённых Dart-файлов — без замечаний. Для этого выпуска тесты повторно не запускались по запросу пользователя. При сборке проверяются подпись APK, версия, архитектура, выравнивание и ресурсы медиакнопок. Аппаратная проверка телефона не выполнялась.
