# PepeHub 0.31.15

**Питомник: исправления по первому знакомству**

* Комната теперь на весь экран: нижняя панель приложения в Питомнике скрыта. Перейти в другие разделы можно круглой кнопкой ▦ «Разделы» сверху справа.
* Окна «Питомцы», «Инкубатор», «Достижения», магазин и гардероб читаются и в тёмной теме приложения: раньше часть текста была белой на светлом фоне, а окна просвечивали.
* Кухня: еда стоит на столе тарелками и больше не закрывает питомца. Питомец сидит за столом и выглядывает из-за него. Нажмите на тарелку, чтобы покормить; если еды нет, откроется магазин.
* Спальня: вместо большой панели две кнопки — свет и аудио на ночь.
* В инкубаторе показаны настоящие яйца вместо цветных кружков.
* Мелочи: читается имя выбранного питомца, подсказка «Почитаем вместе?» не наезжает на кнопки, загрузка комнаты видна над панелями.

Windows x64 и Android ARM64, сборка 132. Android versionCode 2132.
