# Очистка папки проекта

Из корня проекта:

```powershell
./scripts/clean-project.ps1
./scripts/clean-project.ps1 -Apply -WhatIf
./scripts/clean-project.ps1 -Apply
```

Первая команда только показывает план. Вторая проверяет сохранённые пакеты
и ключи, но не удаляет файлы. Третья применяет очистку.

Удаляются результаты `apps/pepehub/build`, кеши компиляции
`.dart_tool/flutter_build` и `.dart_tool/hooks_runner`, прежние дубликаты APK
в `dist` и устаревшие пакеты `dist/online`. Конфигурация зависимостей Dart
сохраняется. Кеши компиляции восстановятся при следующей сборке.

Сохраняются три последних выпуска с корректными локальными каталогами
`artifacts.json`: текущие полные APK/ZIP, дельты и подписанные манифесты.
Этого достаточно для подготовки дельт следующего выпуска и двух предыдущих
локальных версий. Количество можно увеличить: `-KeepReleases 5`.
Будущие неизвестные версии и прочие каталоги `dist` не удаляются.

Исходники, файлы Git, `.local` с настройками и ключами, SDK Flutter/Android,
JDK, кеши зависимостей Gradle/Pub, `node_modules` и вложения чата защищены.
Перед удалением проверяется отсутствие отслеживаемых Git файлов в целях.
Каждая абсолютная цель проверяется на принадлежность проекту, пересечение
с защищёнными путями и junction/symlink в родителях. При обходе результатов
сборки удаляется только сама ссылка, её содержимое не обходится.

Очистка останавливается при работающей сборке или приложении из проекта.
Сохранённые APK/ZIP сверяются с SHA-256 и размерами из каталогов; ключи и
все файлы трёх сохранённых релизов дополнительно сверяются после удаления.
Публичные релизы на GitHub очистка не изменяет.
