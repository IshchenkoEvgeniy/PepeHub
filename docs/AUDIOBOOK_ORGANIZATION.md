# Избранное, коллекции и сортировка аудиокниг

21.09.2026. Добавлено после 0.11.0+24 и включено в выпуск [0.12.0+25](RELEASE_0120.md).

## Управление

- Меню аудиокниги → «В избранное» / «Убрать из избранного». Звезда отображается у названия; фильтр «Избранное» над библиотекой оставляет только отмеченные книги.
- Меню аудиокниги → «Коллекции книги»: можно выбрать несколько коллекций либо создать новую, сразу включив в неё книгу.
- Кнопка «Коллекции» над списком открывает создание, переименование и удаление. Удаление коллекции убирает только принадлежность к ней; книги, файлы, избранное и прогресс остаются.
- Выпадающий фильтр «Все коллекции» позволяет выбрать одну коллекцию. Он совместим с избранным, поиском, корнем библиотеки и вкладками статуса.
- Сортировка: название и автор по возрастанию; прогресс всей книги по убыванию; недавняя активность; сначала короткие / сначала длинные. Активность определяется последним сохранением позиции аудиокниги, а не редактированием её названия. Книги без известной общей длительности остаются в конце сортировки по длительности или прогрессу. При равных значениях порядок определяется названием и ID.

## Хранение и разделение

Используется локальная база: `audio-book:<bookId>` для избранного/принадлежности к коллекциям, `audio-collection:<id>` для названий, `audio-sort` для выбранной сортировки. Сортировка, избранное и состав коллекций сохраняются после повторного открытия. Фильтры списка сбрасываются при переключении раздела.

Текстовые книги продолжают использовать собственные ключи `reading-*`; даже коллекции с одинаковым ID в разных разделах независимы. Для управления переиспользуется общий интерфейс коллекций. Аудио-позиции и файлы не изменяются. Новые настройки пока локальны и не включены в переносимые снимки `.pepehub`; синхронизация остаётся последним этапом.

## Проверки

`audio_organization_test.dart`: порядок по автору/длительности/общему проценту/датам, неизвестная длительность, создание нескольких принадлежностей, избранное, совместные фильтры, переименование/удаление, повторное открытие, независимость от `reading-*` и сохранность аудиопрогресса. Дополнительно проверяются существующие тесты текстовых коллекций, разделения библиотек и дизайна на размере экрана 390×844. Проверки выпуска описаны в [VALIDATION.md](VALIDATION.md).
