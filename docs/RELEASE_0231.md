# PepeHub 0.23.1 — изображения PDF и надёжность библиотеки

Версия **0.23.1+66**, Windows x64 и Android ARM64 (`versionCode=2066`).

- В тёмной теме PDF для областей растровых изображений компенсируется инверсия страницы. Поддерживаются изображения на самой странице и во вложенных form XObjects; извлечение границ выполняется в рабочем потоке PDFium с ограниченным кэшем.
- Исправлена коллизия ключа настроек PDF с записями позиций чтения. Сохранённый режим PDF переносится в отдельный ключ, прежний режим сохраняется.
- Одна повреждённая или посторонняя запись метаданных больше не прерывает загрузку всей коллекции библиотеки.
- Добавлены проверки переноса настройки PDF и определения областей изображений, включая вложенные формы.

**Обновление:** в приложении откройте **Настройки → Обновление приложения → Проверить обновления**. APK устанавливайте поверх текущего приложения, не удаляя его и не очищая данные. Android-сертификат и ключ проверки обновлений используются прежние.

Проверки исходников: **647 passed / 12 skipped**, включая настоящий PDFium; анализ `lib`, `test`, `integration_test` — **No issues found**. Логи: `.local/release-0231-tests.log`, `.local/release-0231-analyze.log`.

Для изображений со сложной прозрачностью, перекрывающим текстом или векторной графики результат может отличаться от исходных цветов. На физическом Android установка и отображение отдельно не проверялись.
