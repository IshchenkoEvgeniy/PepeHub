# PepeHub 0.30.1 — точные позиции TXT

31 октября 2026 · сборка 81 · Windows x64 и Android ARM64.

- Фрагмент книги при сравнении спорных позиций синхронизации теперь учитывает настоящий разделитель абзацев TXT.
- Исправлен перенос старых позиций и цитат из первого формата разметки для глав с одиночными переводами строк.
- TXT с жёсткими переносами строк сохраняют абзацы по пустым строкам. Отдельные строки распознаются как абзацы при преобладании строк с отступами.
- Старые TXT-индексы обновляются последовательно в фоне без открытия каждой книги. Позиции, цитаты и закладки переносятся вместе с индексом; карточки, история и обложки сохраняются.

Устанавливайте обновление поверх текущего PepeHub. Удалять приложение не нужно.
