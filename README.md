# PepeHub

PepeHub — локальная библиотека электронных книг и аудиокниг для Android и Windows. В приложении можно читать, слушать, вести заметки и смотреть историю занятий. Основные функции работают без аккаунта и облачного сервера.

## Что умеет приложение

В PepeHub четыре основных раздела: **«Книги»**, **«Аудиокниги»**, **«Библиотека»** и **«Рекомендации»**. В первых двух можно читать и слушать локальные файлы, искать и сортировать записи, менять сведения о книге, отмечать избранное и собирать собственные коллекции. «Библиотека» получает полные метаданные книг и аудиокниг из Obsidian; добавление локальной книги в Obsidian выполняется отдельной командой. [Подключение и устройство обмена](docs/OBSIDIAN_LIBRARY.md).

«Рекомендации» хранит личные категории и топы, места книг и заметки. По названию, автору или ISBN можно найти карточку в Inventaire, Open Library и Author.Today, проверить метаданные и сохранить. Неизвестные сведения остаются пустыми; дополнение сохраняет ручные исправления. Источники настраиваются отдельно. [Как пользоваться подборками](docs/BOOK_RECOMMENDATIONS.md).

### Электронные книги

Поддерживаются EPUB, FB2, FB2.ZIP, TXT, Markdown, HTML, DOCX, RTF и PDF. Для текстовых книг доступны чтение с прокруткой или перелистыванием, настройка шрифта и темы, поиск и оглавление там, где оно есть в книге. Можно создавать цветные выделения и заметки, добавлять теги и персонажей, а затем искать и фильтровать заметки.

PDF открывается в отдельном просмотрщике с исходной вёрсткой, поиском по текстовому слою, оглавлением, заметками и цитатами. Для EPUB и FB2 поддерживаются главы, сноски и просмотр иллюстраций в отдельной панели; сложная CSS-вёрстка EPUB не воспроизводится полностью.

Приложение автоматически учитывает активное время чтения, новое продвижение по тексту и повторное чтение. Есть календарь, цели, серии дней, статистика по книге и планы чтения с примерной оценкой срока. Автоматический учёт основан на действиях в приложении и делает паузы при бездействии; это оценка активности, а не измерение внимания.

### Аудиокниги

Поддерживаются MP3, M4B, M4A, AAC, OGG, Opus, FLAC и WAV. Можно импортировать файлы или подключить папку и слушать её содержимое без копирования аудиоданных в библиотеку. Несколько файлов можно объединить в одну книгу; приложение сохраняет порядок и общую позицию. M4B может содержать встроенные главы.

В плеере есть скорость воспроизведения, перемотка, таймер сна, обложки, закладки и заметки к позиции. Статистика показывает время и историю прослушивания, календарь, серии и цели. Доступны фильтры, сортировка и объединение пронумерованных частей.

### Статистика и данные

Историю чтения и прослушивания можно просматривать, искать, фильтровать и исправлять. Для явно связанных с Obsidian книг метаданные дополняются автоматически, а журнал, обложки и заметки синхронизируются в обе стороны. В настройках доступны 10 стилей, светлый/тёмный режим, размер текста, компактность, уменьшение анимаций, дневная цель и период обмена. Записи статистики можно копировать в CSV; для аудиостатистики доступен также экспорт JSON. Заметки текстовых книг экспортируются в Markdown или JSON.

Книги, позиции, заметки, планы и статистика хранятся локально на устройстве. Подключённая папка остаётся источником файлов: для аудио PepeHub хранит ссылки и читает оригиналы. Если папку переместить или отозвать доступ к ней, её может потребоваться подключить заново. Импорт отдельных файлов — отдельный сценарий.

## Что пока не входит в текущую версию

- В интерфейсе нет облачной синхронизации между устройствами. Код API/Worker остаётся прототипом для разработки и не является готовым облачным сервисом; аудиофайлы и позиции чтения не синхронизируются.
- Мост библиотеки для существующего Obsidian Habit Timer реализован в исходниках; для живого обмена нужны обновлённый Cloudflare Companion и его миграция D1. Синхронизируются метаданные, журнал чтения/прослушивания, обложки и заметки; файлы книг и аудио не передаются. Прямой файловой синхронизации vault нет.
- Для PDF-сканов без текстового слоя поиск по содержимому и цитирование требуют OCR; встроенного OCR нет.
- DRM-книги, MOBI/AZW, DjVu и некоторые другие форматы пока не поддерживаются. Точная матрица поведения и ограничений — в [описании форматов](docs/FORMATS.md).

## Запуск исходников

Для сборки приложения нужны Flutter SDK, совместимый с ограничениями в [`apps/pepehub/pubspec.yaml`](apps/pepehub/pubspec.yaml), и средства разработки соответствующей платформы. Для Windows нужна Visual Studio с компонентом **Desktop development with C++**; для Android — Android SDK/NDK.

Из корня репозитория в PowerShell:

```powershell
Push-Location apps/pepehub
flutter pub get
flutter run -d windows
Pop-Location
```

Для Android можно собрать ARM64 APK из корня репозитория скриптом:

```powershell
./scripts/build-android.ps1
```

Скрипт использует локальную среду из `.tools`, если она подготовлена. Подробности Android-сборки — в [инструкции](docs/ANDROID.md). Для обычной работы приложения локальный API запускать не нужно.

## Устройство проекта

```text
apps/pepehub/          Flutter-приложение для Android и Windows
contracts/             типы и проверка протокола API
services/sync-worker/  прототип Worker API и миграции D1
integrations/obsidian/  Markdown и мост метаданных существующего Habit Timer
scripts/               локальный API, адаптер SQLite и сборочные скрипты
tests/                 проверки API и Markdown-модуля
docs/                  инструкции, ограничения и история изменений
```

Обзор технических решений: [ARCHITECTURE.md](ARCHITECTURE.md). Не добавляйте в коммиты `.local`, `.tools`, локальные ключи, базу приложения или личные книги.
