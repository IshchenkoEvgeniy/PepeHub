# PepeHub — концепт «Формуляр»

[Открыть концепт](index.html) · [Снимок листа](formular-board.png)

Светлая тема в образе читательского формуляра: строки учёта, даты, отметки штемпелем. Отличается от тёмных направлений «Книжный клуб» и «Фокус» (2026-10-30) и от текущих тем приложения.

## Токены

| Токен | Цвет | Роль |
|---|---|---|
| Картон | `#E2E5DA` | фон экранов |
| Бумага | `#F4F5F0` | карточки, навигация |
| Чернила | `#1F2A44` | основной текст, прогресс |
| Графит | `#5C6371` | вторичный текст |
| Линовка | `#B7C1CE` | разделители строк учёта |
| Штемпель | `#5A3C9C` | даты, отметки, главное действие |

Шрифты: Literata — названия, числа, цитаты; PT Sans — интерфейс. Оба уже есть в `apps/pepehub/assets/fonts`.

## Что предлагается

- Пять разделов вместо шести: «Рекомендации» входят в «Книги → В планах» (ссылка «Подобрать книгу»).
- «Книги»: одна карточка «Продолжить чтение», остальные книги — компактные строки.
- «Библиотека»: только завершено, отложено, брошено. Записи по месяцам, дата завершения — штемпелем; у отложенных пунктирный, у брошенных серый.
- Карточка произведения: штамп «Прочитано» с датой, факты чтения, журнал по дням, цитаты.
- «Статистика»: итог года одной фразой, календарь месяца (дни чтения — заливка, дни завершения — штемпель), часы по месяцам.

Содержимое и числа иллюстративные. Концепт сделан со скиллом `frontend-design` (anthropics/skills). В приложение не переносился.
