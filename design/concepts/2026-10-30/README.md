# PepeHub — концепты четырёх разделов

Два визуальных направления для мобильного приложения. На каждом листе слева направо: годовая статистика, библиотека, медиа, книжные рекомендации. Это макеты для выбора направления; новые функции — предложения, числа и содержимое иллюстративные.

## 01 · Книжный клуб

[Открыть макет](concept-01-book-club.png)

Тёплый графит, медный акцент, светлый текст, заголовки с засечками. Обложки и коллекции занимают центральное место. Более атмосферный вариант личного архива.

## 02 · Фокус

[Открыть макет](concept-02-focus.png)

Тёмный сине-серый фон, мятный акцент, шрифт без засечек, компактные списки и графики. Более практичная структура для повседневного использования и большого каталога.

## Предлагаемые функции

- Статистика: сравнение годов, раздельное время чтения и аудио, подсказка о привычном времени чтения.
- Библиотека: быстрый доступ к коллекциям, цитатам и впечатлениям. Только завершённые, отложенные и брошенные произведения.
- Медиа: блок «Продолжить», следующий урок с длительностью, общая очередь на вечер.
- Рекомендации: подбор по настроению, объёму и наличию серии, объяснение причины рекомендации, действия «В планы» и «Не моё».

Практическая отправная точка — структура «Фокуса»; тёплую палитру и работу с обложками можно взять из «Книжного клуба».
