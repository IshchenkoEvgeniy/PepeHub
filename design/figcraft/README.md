# Окна PepeHub в FigCraft

Генератор макета `PepeHub.figcraft` со всеми основными окнами приложения в виде редактируемых слоёв: auto layout, реальный текст, векторные иконки Material.

```
node design/figcraft/build.js [путь.figcraft] [--only=Имя фрейма,Имя фрейма]
```

По умолчанию файл пишется в `C:/Users/<пользователь>/FigCraft/pepehub/PepeHub.figcraft`. Нужен FigCraft 0.18+ (`figcraft-cli.exe`); путь к нему можно задать в `FIGCRAFT_CLI`.

## Что внутри

| Страница | Фреймы |
|---|---|
| Книги | десктоп (сетка), телефон (список) |
| Аудиокниги | пустая полка, плеер (десктоп, телефон), мини-плеер |
| Медиа | пусто, библиотека, телефон |
| Библиотека | архив (десктоп с карточкой справа, телефон), карточка произведения |
| Рекомендации | десктоп, телефон, карточка рекомендации |
| Статистика | летопись и книжный календарь, чтение, прослушивание, журнал сессий, цели и напоминания |
| Чтение | читалка (десктоп, телефон), заметки и цитаты |
| Настройки | интерфейс, чтение и аудио, библиотека и файлы, телефон, данные библиотеки, папки книг |
| Служебные окна | скрытые и недоступные, добавить серию, план чтения, карточки Anki, журнал ошибок, обмен статистикой, обновление, диалог удаления, меню книги, снекбар |

Переменные: коллекция «Палитра», переменные `Color/*`, по одному режиму на каждую тему из `AppStyle` (`lib/ui/app_theme.dart`).

## Устройство

- `lib.js` — DSL (`F`, `H`, `V`, `T`, `I`, …) и компиляция дерева в команды FigCraft. Цвета палитры «Синий» — в `C`.
- `components.js` — рейл, нижняя панель, заголовок, поиск, чипы, кнопки, обложки.
- `screens/*.js` — экраны. Каждый модуль экспортирует массив фреймов, порядок страниц задаёт `build.js`.
- `icons.json` — контуры Material Icons из шрифта Flutter. Пересобрать: `npm i --no-save opentype.js@1.3.4`, затем `node design/figcraft/extract-icons.js`. Нужен собранный `apps/pepehub/build/unit_test_assets`.

## Эталоны

Реальные экраны рендерит `apps/pepehub/test/readme_screenshots_test.dart`:

```
PEPEHUB_README_SCREENSHOTS=1 PEPEHUB_SCREENSHOT_OUT=<папка> \
PEPEHUB_SCREENSHOT_FILTER=books-desktop,audio-desktop,work,... flutter test test/readme_screenshots_test.dart
```

Без `PEPEHUB_SCREENSHOT_FILTER` рисуется только галерея README. Дополнительные окна (`audio-desktop`, `video-desktop`, `work`, `reading-statistics`, `goals`, …) рендерятся, только если они перечислены в фильтре.

## Шрифты

Onest, Oswald, Cormorant Garamond и Lora лежат в `apps/pepehub/assets/fonts`. Генератор подгружает их только на время сборки. Чтобы макет выглядел правильно в приложении FigCraft, установите эти шрифты в систему.
